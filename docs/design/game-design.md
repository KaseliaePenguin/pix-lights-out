## 2. コンセプトと面白さの柱

**「しっかりブレーキ、きれいなライン、立ち上がりで踏む」見下ろし型 F1。**
2〜3 分で終わる短いレースに、スタートの反応、ブレーキング、ライン取り、スリップストリームと DRS からの追い抜き、タイヤ戦略を詰め込む。

面白さの柱 (仕様判断に迷ったらここに戻る):

1. **ブレーキングとライン取りが気持ちいい** (第 5 版): コーナーの手前でブレーキを踏んで減速し、ハンドルを切ればグリップで気持ちよく曲がる。キーボードで押しっぱなしにするとちょうどグリップの限界で曲がり、ハンドルを切っただけでは減速しない。差がつくのは、ブレーキを始める位置、ライン、アクセルを踏み始めるタイミング。操作はキーボードで扱いやすい穏やかな速さにし、限界を超えたときの罰 (膨らみ、芝生、壁) は軽くする。詳細は car-physics.md 0 節
2. **抜く・抜かれるの駆け引き**: スリップストリーム、DRS、ブレーキング勝負で追い抜きが起きる。体当たりは得にならない (当てた側も損をする)
3. **短い時間に戦略がある**: 3 周でも「ソフトとハードをどの順でいつ履くか」でレース展開が変わる (義務ピット)
4. **中継の気分**: 順位表のタイム差、区間タイムの紫/緑、ファステストラップ通知など、F1 中継風の情報で「いま何が起きているか」が分かる
5. **1 周がすぐやり直せる**: タイムアタックはリトライが速く、自己ベストのゴーストと競える

## 3. コアループ

```
[走る] コーナーごとにブレーキ・ライン・アクセルの判断
   ↓ 結果がすぐ返る (区間タイムの色、前車との差、ゴースト差)
[比べる] 自己ベスト/ライバルとの差を知る
   ↓
[改善する] 次の周・次のレースでブレーキを遅らせる、ラインを変える、戦略を変える
   ↓
[記録・順位が上がる] 自己ベスト更新、ゴースト更新、表彰台
```

- 短いループ (数秒): 1 コーナーごとの成否 (ブレーキの位置、曲がる手応え、スキール音、立ち上がりの速度)
- 中くらいのループ (約 40 秒。目安は sim で測り直す、11.1 節): 1 周ごとの区間タイム・ラップタイム・順位変動
- 長いループ (2〜3 分): レース結果、戦略の成否、自己ベスト更新

## 5. 操作

### 5.1 キーボード

| 操作 | キー (`KeyboardEvent.code`) | 取得方法 |
| --- | --- | --- |
| アクセル | `KeyZ` | `isDown` |
| ブレーキ / 後退 | `KeyX` | `isDown` (停止中に 0.3 秒押し続けると後退) |
| 左に曲がる | `ArrowLeft` | `isDown` |
| 右に曲がる | `ArrowRight` | `isDown` |
| DRS | `Space` | `wasPressed` (開くだけ。閉じるのはブレーキ/区間終了) |
| コース復帰 | `KeyR` | `wasPressed` (条件を満たすときのみ有効、7.11 節) |
| ポーズ | `Escape` | `wasPressed` (マルチでは一時停止せずメニューを重ねて表示) |
| ピットでのタイヤ選択 | `ArrowLeft`/`ArrowRight` | `wasPressed` (ピット停止中のみ。自動運転中なのでステアと衝突しない) |
| デバッグ表示 (開発用) | `F3` | `wasPressed` (表示位置は画面左、x12 y208。右上のタイム・左上の順位表と重ならない) |

- **キー配置はユーザー決定 (2026-09-25)**: 右手の矢印キーでハンドル、左手の Z / X でアクセル / ブレーキ。アクセルとブレーキを別の指に分け、曲がりながらブレーキを踏めるようにする (↑↓・WASD での運転は廃止)
- メニュー: 上下で選択、`Enter` / `Space` で決定、`Escape` で戻る
- ステアリングは **車基準** (左キー = 車から見て左へ曲がる)。カメラの既定は車の向きに合わせて回転する表示 (10.5 節) なので、画面上の左右と一致する。設定で北が上の固定表示にした場合は、南向きに走っているときに画面上の左右と逆になる
- キーボードの左右は 0/1 の入力だが、車側で滑らかに立ち上げる。立ち上がりは約 0.29 秒で、キーボードでも急すぎない穏やかな速さにする (ユーザーの調整。car-physics.md 4 節)
- ブレーキを踏みながらハンドルを切ると、横グリップが 20% 落ちる。「まっすぐブレーキ → 離して曲がる」のが基本 (car-physics.md 6 節)。ドリフトの操作はない (第 5 版で削除)
- キー割り当ての変更機能は作らない (14 章)

### 5.2 ゲームパッド (決定: M3 で対応)

Gamepad API の標準マッピング (`gamepad.mapping === 'standard'`) を使う。最初に接続された 1 台だけを使う。

| 操作 | ボタン (標準マッピング) | 入力の扱い |
| --- | --- | --- |
| アクセル | RT (`buttons[7].value`) | アナログ 0〜1。デッドゾーン 0.05 |
| ブレーキ / 後退 | LT (`buttons[6].value`) | アナログ 0〜1。デッドゾーン 0.05 |
| ステア | 左スティック X (`axes[0]`) | アナログ -1〜1。デッドゾーン 0.15 と応答カーブ (car-physics.md 4 節) |
| ステア (予備) | 十字キー左右 (`buttons[14]` / `buttons[15]`) | キーボードの左右と同じ扱い (0/1 を平滑化) |
| DRS | A (`buttons[0]`) | 押した瞬間 |
| コース復帰 | Y (`buttons[3]`) | 押した瞬間 |
| ポーズ | Start (`buttons[9]`) | 押した瞬間 |
| メニュー: 選択 | 十字キー / 左スティック (0.5 以上倒す、長押しは 0.4 秒後から 0.12 秒間隔でリピート) | |
| メニュー: 決定 / 戻る | A (`buttons[0]`) / B (`buttons[1]`) | |
| ピットでのタイヤ選択 | 十字キー左右 / 左スティック左右 | 押した瞬間 |

- キーボードとゲームパッドは同時に使える。アクセル・ブレーキは大きい方の値、ステアは絶対値が大きい方の値を採用する
- 「押した瞬間」の判定は、前の更新フレームで押されていなかったボタンが押されたとき (キーボードの `wasPressed` と同じ考え方)
- `src/core/Input` の拡張が必要なので game-engineer の担当。操作説明画面 (HelpScene) にゲームパッドの割り当ても載せる
- アナログではハンドルを浅く切れるので、細かいライン取りがしやすい。キーボードは、フルステアがちょうどグリップの限界になる設定と、キーを軽く叩くと浅く切れる穏やかなステアの速さ (car-physics.md 4・6 節) で、不利を小さくしている

### 5.3 入力の抽象化 (実装上の要件)

車は `Controls` (throttle 0〜1, brake 0〜1, steerInput -1〜1, steerIsAnalog, drsPressed, resetPressed) だけを見て動く。キーボード・ゲームパッド・CPU の AI・ゴーストの再生・ネットワークは、どれも `Controls` か車の状態を作る側として実装する。M4 のマルチで同じ物理計算をホストの Web Worker と共有するための前提。

## 7. レースのルール

### 7.1 セッションの種類

| セッション | 目的 | 周回 | 他車との接触 | スリップストリーム | タイヤ摩耗 | DRS | ピット |
| --- | --- | --- | --- | --- | --- | --- | --- |
| タイムアタック | 自己ベスト更新 | 無制限 | なし (ゴーストのみ) | なし | なし (ソフト固定) | 区間内で自由に使用可 | 入れない (入ると周回無効) |
| 予選 | グリッド決定 | 計測 2 周 | なし (全車ゴースト) | なし | あり (ソフト新品で開始) | 区間内で自由に使用可 | 入れない (入ると周回無効) |
| 決勝 | 順位を競う | 3 周 (標準) / 5 周 | あり | あり | あり | 条件付き (7.6 節) | あり、義務 1 回 (8 章) |

### 7.2 スタート (決勝)

1. 全車がグリッドに並ぶ (7.3 節)。操作は受け付けるが、この時点で動くとフライングになる
2. 1.0 秒後から、スタートランプのユニットが左から 1.0 秒間隔で 1 つずつ点灯する (計 5 ユニット。表示は style-guide.md §6)。点灯ごとに `start-light-on` を鳴らす
3. 5 つ点灯したあと、**0.5〜2.5 秒のランダム時間** (一様分布) 待って全消灯 = スタート (`start-go`)
4. 消灯の瞬間からレース時間の計測を開始する。メッセージ帯に反応時間 (消灯からアクセルを踏むまで) を `REACTION 0.231` の形で 2 秒表示する

BGM: グリッドに並んだ時点で BGM を止め (ゲイン 0)、消灯と同時にレース BGM を頭から再生する (sound-guide.md §2)。

フライング:

- 判定: 消灯前に車がグリッド位置から **5 px 以上** 動いたら成立する (1 回のみ判定)
- 罰則: **ゴールタイムに +3 秒**。成立した瞬間に `false-start` を鳴らし、メッセージ帯に `JUMP START +3 SEC` を表示する。リザルトにペナルティとして載せる
- 車はそのまま走れる (止めない)。CPU は消灯後に発進する (反応時間は 9.2 節) のでフライングしない
- マルチではホストが消灯時刻を決め、各クライアントの位置報告から判定する

### 7.3 グリッド

- コントロールライン (スタート/フィニッシュライン) の手前に 2 列の千鳥配置 (枠の絵は style-guide.md §5)
- k 番手 (k = 0〜7) の位置: コントロールラインから中心線沿いに **25 + 50k px** 後方。横方向は中心線から **k が偶数なら -15 px、奇数なら +15 px** (ポールは次の 1 コーナーのイン側。左右はコースデータで指定)
- 車の向きはコースの進行方向
- グリッド順: 予選順位
- **予選をスキップした場合 (決定)**: プレイヤーは最後尾。CPU は予選タイムの計算式 (7.8 節) で予選を走ったものとして計算し、その順に前から並べる (腕前の高い CPU ほど前になりやすい)

### 7.4 周回とチェックポイント

- コースには進行順に並んだ **チェックポイント** (約 750 px ごと、1 周 20〜26 個) があり、各車は「次に通るべきチェックポイント番号」を持つ
- 次のチェックポイントを通過したときだけ番号が進む。コントロールラインは番号 0 のチェックポイントで、全チェックポイントを通過した状態で通ったときだけ周回数 +1
- チェックポイントは線分 (ゲート) で、幅はコース + 外側のランオフ全体 (コースアウトしただけでは無効にならない)。ショートカットできる場所 (シケインのイン側など。コース 1 にはない) だけはゲートの外にする
- 次のチェックポイントを飛ばして先のゲートを通った場合は「チェックポイント未通過」状態になる。メッセージ帯に `MISSED CHECKPOINT` を出し、画面端に未通過ゲートの方向を示す矢印を出す。この状態ではコース復帰 (7.11 節) がいつでも使える
- チェックポイント未通過の解除: 飛ばしたゲートを (引き返して) 前向きに通るか、コース復帰を使うと解除する。予選・タイムアタックでは、未通過になった時点でその周は無効になる (解除しても有効には戻らない)
- グリッドはコントロールラインの手前なので、スタート直後の最初の通過は周回に数えない (1 周目の開始)。1 周目のラップタイムは消灯から計測する

### 7.5 順位とタイム差

- 進行距離 `P = 周回数 × 1 周の長さ + 中心線上の位置` で順位を決める。中心線上の位置は「直前に通過したチェックポイント」と「次のチェックポイント」の間に制限する (ショートカットで順位が上がって見えないように)
- ゴールした車はゴール順が優先
- **タイミングライン**: 中心線沿いに 250 px ごと (1 周 約 71 本) に置き、各車の通過時刻を記録する
- 前車とのタイム差 = 自分が最後に通過したタイミングラインの時刻 − 前車が同じ周・同じラインを通過した時刻。ライン通過ごとに更新する
- 後続車とのタイム差 = 後続車が最後に通過したラインの時刻 − 自分が同じ周・同じラインを通過した時刻
- 表示: 1 分未満は `+1.234`、1 分以上は `+1:02.345`、周回遅れは `+1 LAP`
- 区間 (セクター): **3 区間**。境界はコースデータで指定し、所要時間が概ね均等になる位置にする (コース 1 の位置は 11.2 節)

### 7.6 スリップストリームと DRS (ルール面)

数値と判定の詳細は car-physics.md 11・12 節。

- スリップストリーム: 決勝のみ有効 (予選・タイムアタックは全車ゴーストのため効かない)
- DRS 区間: コースに 1 か所 (バックストレート)。区間の手前に **検知ライン** を置く
- 決勝では、**2 周目以降**、検知ラインで前車とのタイム差が **1.000 秒以内** なら、その周の DRS 区間で使える。使えるようになったら `drs-available` を鳴らし、区間に入ったときにメッセージ帯に `DRS ENABLED` を出す
- 予選・タイムアタックでは、DRS 区間内なら条件なしで使える
- 使える状態で区間内に入ったら DRS ボタンで開く。ブレーキを踏むか区間の終わりに来ると自動的に閉じる。一度閉じたら、その区間では再度開けない

### 7.7 レースの終了と順位確定

- 先頭車が規定周回を終えた時点でチェッカーフラッグ。以降、各車は次にコントロールラインを通過した時点でゴール
- 先頭車のゴールから **30 秒** 経ってもゴールしていない車は、その時点の順位で「未完走 (+n LAP)」
- 1 人用: プレイヤーがゴールした時点で、残りの CPU のゴールタイムを「残り距離 ÷ その CPU の直近 1 周の平均速度」で推定して即座に確定し、リザルトへ進む (待たせない)
- 最終順位 = ゴールタイム + ペナルティ (フライング +3 秒、義務ピット未消化 +30 秒) の小さい順。並びは、ゴールした車 → 未完走の車 (進行距離順) → リタイアの順
- 1 人用ではポーズメニューから「リタイア」できる (結果は DNF、順位表の表示は `OUT`)
- マルチではホストが最終順位を確定して `result` で送る

### 7.8 予選

- 開始位置: コントロールラインの **600 px 手前** (コース 1 では最終コーナー T11 の出口から約 300 px) に停止した状態。第 3 版の 875 px のままだと、コース 1 ではヘアピンの途中から発進することになるため変えた。画面中央のカウント 3-2-1 (10.2 節) のあと発進する (スタートランプは使わない)
- 計測 2 周。有効な周のうち速い方がその車の予選タイム。2 周目の終了でセッション終了
- 周回が無効になる条件: チェックポイント未通過、コース復帰の使用、ピットレーンへの進入。無効になった時点でメッセージ帯に `INVALID LAP` を出し、その周のタイムを灰色にする。ただしコース復帰が原因の場合は `INVALID LAP` を出さない (10.2 節)
- 全車ゴースト (接触なし)。マルチでは全員同時に同じ位置から出るが、重なっていても問題ない
- 1 人用の CPU は実際には走らせず、タイムを計算で出す: `CPU 予選タイム = コースの基準タイム × (1 + (1 − 腕前) × 1.2) + 乱数(−0.2〜+0.4 秒)`。基準タイムは腕前 1.0 の CPU の実測ラップ (コースデータに記録する)
- 有効なタイムがない車はグリッド後方 (その中ではランダム)
- 予選に制限時間はない (sound-list.md の `qualifying-countdown` は使わない)

### 7.9 接触

- 車同士に当たり判定がある (決勝のみ)。当てた側 (接近速度が大きい側) のほうが大きく減速し、強く当てると当てた側がスピンする。当てられた側が押されて速くなることはない。数値は car-physics.md 9 節
- 壁 (ランオフの外側のタイヤバリア) にも当たり判定がある
- 車のダメージ (壊れる・遅くなる) はない

### 7.10 ゴースト (すり抜け) になる条件

| 条件 | 対象 | 期間 |
| --- | --- | --- |
| 周回遅れの関係 | 2 台の進行距離の差が 1 周の長さの半分以上ある組み合わせ | 条件を満たす間ずっと (その 2 台の間だけ) |
| コース復帰直後 | 復帰した車 ↔ 全車 | 操作再開から 3.0 秒 |
| ピットレーン走行中 | ピットレーン内の車 ↔ 全車 | ピット入口ラインからピット出口ラインまで + 出口後 1.0 秒 |
| 予選・タイムアタック | 全車 | 常時 |
| マルチで車の状態が届かない (タブを裏に回した、回線が詰まったなど。ホスト本人も同じ) | その車 ↔ 全車 | 状態が 3 秒届かなかった時点から、再び届くまで。その間はその場で止まったまま。**60 秒** 届かなければリタイア扱い (接続は切らず、ロビーに戻れば次のレースに出られる)。network.md「ホストのタブがバックグラウンドに回ったときの対策」 |

- 期間の終わりに他車と重なっている場合は、重ならなくなるまでゴーストを延長する
- ゴースト中の車の描き方: style-guide.md は半透明を使わない方針なので、見せ方 (1 ドット間引きの市松で描く、点滅させるなど) は art-director が決める。コース復帰直後とピット出口後は、通常のゴーストと区別できるよう点滅 (4 回/秒) させる
- 周回遅れの関係は、合意済みの「周回遅れの車は数秒ゴースト」を「周回遅れの組み合わせは接触しない」という形で実現したもの。判定が単純で、全クライアントで結果が一致しやすい。半周以上の差があるので、実際に近づくのは追い抜きの瞬間だけ
- 周回遅れの車に、後ろ 190 px 以内まで周回遅れにする側の車が来たら、周回遅れの車のメッセージ帯に `BLUE FLAG` を出す (知らせるだけで罰則はない)

### 7.11 コース復帰 (リセット)

使える条件 (決勝・予選・タイムアタック共通。スタート前・ピットレーン内・スピン中・復帰の途中、**復帰後の操作再開から 3.0 秒間 (自車の点滅中)** は不可):

- 速度 62.5 px/秒 未満が 1.0 秒以上続いている、または
- 4 輪すべてがコース外 (芝生・砂利) の状態が 1.5 秒以上続いている、または
- 逆走警告 (10.3 節) が出ている、または
- チェックポイント未通過状態

条件を満たすとメッセージ帯に `PRESS R TO RESET` (ゲームパッド接続時は `PRESS Y TO RESET`) を出す。満たさないときに押すと `ui-error` を鳴らす。

手順:

1. 0.3 秒で画面を暗転する (自分の画面だけ。マルチでも他の人の画面には影響しない)
2. 「最後に正常に走っていた地点」(コース上で、チェックポイントの順序も正しかった最後の位置) から、中心線沿いに **150 px 手前** に置き直す。位置は中心線上、向きは進行方向、速度は 0
3. 0.3 秒で明転し、**1.5 秒** 操作不能にする (メッセージ帯に `RESET` とカウントを表示)
4. 操作再開と同時に 3.0 秒のゴーストにする (7.10 節)

置き直しと停止からの加速を含めて、約 4 秒の損失になる。ペナルティとして十分で、ショートカットの得にもならない。予選・タイムアタックでは、その周は無効になる。

- 復帰後 3.0 秒の使用禁止 (決定): 置き直した直後は速度 0 なので、禁止しないと「速度 62.5 px/秒 未満が 1.0 秒」の条件をすぐ満たし、`PRESS R TO RESET` が出て連打で復帰を繰り返せてしまう。禁止期間は 7.10 節のゴースト期間 (点滅中) と同じにし、見た目と一致させる。禁止期間の終わりから、通常どおり条件を数え始める (速度 62.5 px/秒 未満の 1.0 秒などは、禁止期間の終わりから計る)。禁止期間中に押した R は `ui-error`
- 復帰による周回無効では `INVALID LAP` を出さない (決定): メッセージ帯が 1 件ずつなので、`INVALID LAP` (優先度 3) が `RESET` のカウント (優先度 4) を隠してしまう。復帰は自分で選んだ操作で、周が無効になるのは分かっているため、タイムを灰色にするだけで伝える。チェックポイント未通過・ピットレーン進入が原因のときは従来どおり出す

## 8. ピットとタイヤ

### 8.1 3 周レースで意味を持たせる方法 (決定)

検討した選択肢:

| 案 | 内容 | 評価 |
| --- | --- | --- |
| A. 摩耗だけ | ソフトは速いが 3 周目に崖 | ピットの損失 (約 6.5 秒) を取り返せないため、誰もピットに入らない。ピットの意味が薄い |
| B. 義務ピット 1 回 | 1 回タイヤ交換必須 | 同じタイヤを 2 回履くのが最速になり、選択の幅が狭い |
| **C. 義務ピット 1 回 + 2 種類使用義務** | ソフトとハードを両方使う | **採用**。「どちらを先に履くか」「何周目に入るか」の 2 軸で展開が分かれる |
| D. 周回数を長くする | 8 周以上 | 合意済みの「標準 3 周・約 3 分」と合わない。5 周の選択肢だけ追加する |

決定:

- 決勝では **ソフトとハードの両方を使う義務** がある。スタート時のタイヤとピットで履いたタイヤで判定するので、実質 **1 回以上のピットイン** が必要になる
- 義務を果たさずにゴールした場合は **+30 秒** (ピットの損失約 6.5 秒より十分大きく、義務を無視しても得がない)
- 義務の状態は車両状態パネルに表示する (10.1 節)。最後にピットに入れる周 (最終周の 1 つ前の周) に入った時点で未消化なら、メッセージ帯に `BOX BOX` を出す
- 周回数は 3 周 (標準) / 5 周 から選べる

想定されるレース展開 (初版のコース案でのシミュレーションによる目安。コース 1 確定後の理想ラップではソフトとハードの差が約 0.6 秒/周に縮んだので、M3 で摩耗を入れたあとに測り直す):

| 戦略 (3 周) | 1 周目 | 2 周目 | 3 周目 | 合計の差 (ピット損失を除く) |
| --- | --- | --- | --- | --- |
| ソフト 2 周 → ハード 1 周 | 速い | やや速い | 遅い | 基準 |
| ハード 1 周 → ソフト 2 周 | 遅い | 速い | やや速い | 基準と同じ |
| ソフト 1 周 → ハード 2 周 | 速い | 遅い | 遅い | +0.7 秒 |
| ハード 2 周 → ソフト 1 周 | 遅い | 遅い | 速い | +0.7 秒 |

- 上の表は第 5 版の物理で M3 に測り直す
- ソフト 2 周が最もバランスが良いが、滑らせる走りをするとソフトが 2 周目で崖に入る (car-physics.md 10 節)。「ソフトで前に出て守る」か「ハードで耐えて、最後に新品ソフトで追う」かの選択になる
- 前の車より先にピットに入り、新品タイヤで差を詰める (アンダーカット) も成立する
- スタートタイヤはレース設定で選ぶ (マルチはロビーで各自が選ぶ)

### 8.2 タイヤの種類 (決定: ソフトとハードの 2 種類)

| 種類 | アイコン (style-guide.md §6) | グリップ | 摩耗の速さ (1 周の目安) |
| --- | --- | --- | --- |
| ソフト | `S` 赤 | ×1.08 | 約 34% |
| ハード | `H` 白 | ×0.96 | 約 14% |

- 摩耗が 70% を超える (残り 30% 未満になる) と急にグリップが落ちる (崖)。100% で止まり、それ以上は悪化しない (パンクなし)。HUD の摩耗バーの色の境目 (残り 30% で赤) と崖の位置は一致させている
- 摩耗で変わるのはグリップ (旋回の限界とブレーキ) だけ。最高速・加速は変わらない
- 詳細な式は car-physics.md 10 節
- ミディアム・インターミディエイト・ウェットは使わない (3 周では違いが出にくく、選択が複雑になるだけ。天候の変化もない)。style-guide.md のアイコン一覧にある `icon-tyre-medium` / `inter` / `wet` は作らなくてよい

### 8.3 ピットレーン

コース上の配置 (第 4 版のコース 1、11.2 節): ピットレーン (幅 64 px) はメインストレートの **左側** (周回の外側、中心線から 110 px) に平行に置き、**入口と出口の両方をメインストレート上** に置く。長さは 1,676 px (実装)。ピットレーン内でもコントロールラインの通過は有効 (周回が数えられる)。

| 位置 | 場所 (コース 1 の区間名) | 中心線上の位置の目安 |
| --- | --- | --- |
| 分岐 (入口ライン) | 最終コーナー T11 の出口から約 250 px 先 (`main0` の約 28%) | コントロールラインの約 650 px 手前 |
| ボックス 8 か所 | コントロールラインの前後 | |
| 合流 (出口ライン) | コントロールラインから約 1,000 px 先 (`main1` の約 53%) | T1 手前のブレーキングゾーン (幅 90 px、T1 の 400 px 手前から) より約 500 px 手前 |

- 左側に置く理由: メインストレートの右側 (内側) は、最終コーナー T11 のヘアピンの反対側の直線 `st10` と、高速コーナー T10 が 240〜285 px の距離にあり、ピットレーンを置く幅がないため。左側 (外側) は空いている。T1 は右コーナーなので、ピット出口の合流は T1 のアウト側になり、ブレーキングゾーンの前で本線に戻れる
- 分岐と合流の斜めの部分 (約 200〜300 px かけて横に 110 px ずらす) も長さに含める
- グリッド (コントロールラインの手前 約 400 px、7.3 節) はピットレーンの横に並ぶが、レーンは中心線から 110 px 離れているので重ならない
- 入口の案内 (下の「PIT」看板と路面の矢印) は、入口ラインの 375 px 手前 = T11 の途中になる。T11 の出口の外側に看板を置き、路面の矢印は T11 の出口から入口ラインまでに描く
- 数値の根拠: 225 px/秒 で 1,676 px を走ると 7.4 秒 (下の損失の計算に使っている値)

M1 の扱い: ピットに入れる理由がなく、進入すると周回が無効になるだけ (7.1 節)。コース 1 を作り直すときに、最初から上の形で作る。

状態遷移 (ピット入口ラインを越えた時点から自動運転):

```
RACING ──(ピット入口ラインを通過)──→ PIT_IN
PIT_IN   : 自動運転。速度制限 225 px/秒 まで自動でブレーキ (減速度は `brakeDecel`、ユーザーの調整で 312.5 px/秒²)。操作は無効
  ↓ ピットレーン本線に到達
PIT_LANE : 自動運転で 225 px/秒 を保ち、ピットボックスへ向かう
  ↓ ボックス到着 (停止)
PIT_STOP : 2.0 秒停止してタイヤ交換。左右でタイヤを選ぶ (停止から 1.5 秒まで変更可)
  ↓ 交換完了 (摩耗 0% の新品になる)
PIT_OUT  : 自動運転で 225 px/秒、ピット出口ラインまで
  ↓ ピット出口ラインを通過
RACING   : 操作が戻る。速度制限を解除。ゴースト 1.0 秒 (7.10 節)
```

- ピットレーン内は全車ゴースト (接触なし)。自動運転なので渋滞や衝突の処理は要らない。ボックスは 8 台分で、各車に自分の車番のボックスを割り当てる
- タイヤ選択の既定値: 2 種類使用義務が未消化なら「今と違う種類」、消化済みなら「ソフト」
- ピットインの損失は約 6.5 秒 (レーン走行 7.2 秒 + 停止 2.0 秒 − 同じ区間をコースで走る約 3.3 秒 + 減速・加速分)
- 最終周にピットレーンに入った場合は、ドライブスルー (停止・交換なし) で通過する
- 予選・タイムアタックでピットレーンに入った場合も同じ自動運転で通過し、その周は無効になる
- ピットに入る意思表示のボタンは作らない (入口に向かって走れば入る)。誤って入らないよう、入口ラインの 375 px 手前に路面の矢印と「PIT」看板を置く
- 音: 速度制限中は `pit-limiter-beep`、交換中は `pit-wheelgun` (4 輪ぶん少しずつずらす)、完了時は `pit-release`

## 9. CPU 車

### 9.1 走り方

- コースデータの **レーシングライン** (中心線とは別の折れ線で、各点に目標速度を持つ) に沿って走る。目標速度は曲率半径 R から `√(latGrip × タイヤのグリップ × R) × 腕前` で事前に計算する (`latGrip` は car-physics.md 6 節の値。第 4 版では 750)
- ステア: レーシングライン上の先読み点 (距離 50 px + 速度 × 0.25 秒) に向けて曲がる (pure pursuit)。出力はアナログのステア量 (`steerIsAnalog = true`)
- アクセル・ブレーキ: 先の目標速度に間に合うブレーキ開始点を、減速度 `brakeDecel × グリップ × 0.95` で計算して判断する
- プレイヤーと同じ物理で走る (`Controls` を出力する)。ズルはしない

### 9.2 難易度

| 難易度 | 腕前 (目標速度とブレーキの倍率) | コーナーでのミス率 | スタート反応 |
| --- | --- | --- | --- |
| Easy | 0.88 | 8% (ブレーキ開始が 37.5 px 遅れてふくらむ) | 0.30〜0.40 秒 |
| Normal | 0.94 | 4% | 0.20〜0.32 秒 |
| Hard | 0.98 | 1.5% | 0.15〜0.25 秒 |

- 各 CPU の腕前に ±0.01 の個体差を付ける (同じ難易度でも速い車と遅い車ができる)
- ラバーバンド (遅れた車を速くする補正) は **入れない**。実力差は難易度の選択で調整する

### 9.3 レース中の判断

- 追い抜き: 前車が 100 px 以内にいて自分より遅いとき、空いている側へ最大 25 px ラインをずらす (最大 3 秒)
- 追突回避: 前車が 50 px 以内で接近しているときはブレーキ
- DRS: 使えるなら区間に入ってすぐ開く
- タイヤ戦略: 規則を満たす戦略 (8.1 節の 4 通り) からランダムに選ぶ。Hard の CPU は、ソフト 2 周の戦略を選ぶ確率を高く (60%) する
- スタックしたら (速度 62.5 px/秒 未満が 2 秒) コース復帰を使う

- 速度の表示: `km/h = px/秒 × 0.6` (最高速 525 px/秒 = 315 km/h)。縮尺どおりに換算すると (1 px ≒ 0.14 m) 265 km/h になるが、F1 らしい数字にするため 1.2 倍の演出値にする
- ギアの表示: 物理にギアはないが、表示とエンジン音 (sound-guide.md §3) のために速度から「仮想ギア」を決める。7 速で、各ギアの上限速度は 1 速 110 / 2 速 190 / 3 速 265 / 4 速 340 / 5 速 410 / 6 速 470 / 7 速 620 px/秒。シフトアップは今のギアの上限を超えたとき、シフトダウンは下のギアの上限より 10 px/秒 低くなったとき (行ったり来たりを防ぐ)。回転数は次の 2 つを持つ (どちらも 0〜1)

- 優先度は数字が小さいほど高い。表示中に優先度の高いメッセージが来たら差し替える。低いものは待たせ、3 秒以上待ったら捨てる

- 自分の順位が変わったことは順位表の色 (10.1 節) と `position-change` の音で伝え、メッセージ帯には出さない

### 10.3 警告

- 逆走: 車の向きとコースの進行方向の差が 120° を超えた状態で、前進速度 37.5 px/秒 以上が 1.0 秒続いたら `WRONG WAY`。スピン中は数えない
- 逆走の解除: 前を向き直した (差が 90° 未満になった) とき、または止まった (速度 37.5 px/秒 未満) とき、あるいはコース復帰を使ったときに消す。120° と 90° の差は、境目で出たり消えたりするのを防ぐため
- チェックポイント未通過: 7.4 節 (解除の条件も同じ節)

### 10.5 カメラ

**表示の方式 (ユーザーの要望、2026-09-25)**: 設定の CAMERA で選ぶ。既定は ROTATE。

| 設定 | 見え方 |
| --- | --- |
| ROTATE (既定) | 車の進行方向 (滑り角を含まない heading) が画面の上になるよう、なめらかに回す。時定数 0.35 秒 (ユーザーの調整に合わせて 0.25 → 0.35) で追い、スピン中・後退中は止め、前進 60 px/秒 未満では時定数 1.5 秒でゆっくり回す。コース復帰・スタートではすぐに向きを合わせる。先読みは前方 (画面の上) に `40 + 速さ × 0.25` px (最大 150 px) |
| FIXED | 北が常に上。以下の箇条書きはこの方式の決まり |

- ROTATE STEP (角度を 64 段階に丸める方式) は試作したが、ユーザーの決定で廃止した (2026-09-26)。設定は ROTATE / FIXED の 2 つ
- 回転する表示では、ワールド層 (504×504 ドット) を回転してニアレストネイバーで 2 倍に転送する。ドットは画面上で正方形にならない (style-guide.md §1 の例外。art-director の確認待ち)。車は画面に直接描き、HUD とミニマップは回転しない

**FIXED の決まり**:

- 北が常に上 (回転しない)。倍率は固定 (ワールドの 1 ドット = 画面の 2 px)
- 追従先 = 自車の位置 + 速度ベクトル × 0.4 秒 (長さは最大 190 px)。進行方向の先が多く見える
- カメラは追従先へ指数的に近づける: `camera += (target − camera) × (1 − e^(−4 × dt))`
- ただし、自車が画面中央から横 ±250 px、縦 ±170 px の外に出ないよう制限する (画面上の距離)
- 画面揺れはカメラ位置に加える
- 描画時はカメラ位置をドット単位 (2 px 単位) に丸める (style-guide.md §1)
- スタート前は、グリッド上の自車を画面の中心に置く

#### 閉じることの確かめ方 (第 3 版の案は閉じなかったため)

1. **角度の合計**: 全コーナーの角度 (右が正) の合計が **+360°** (時計回りで 1 周) になること。コース 1: 90 − 90 + 90 + 90 + 40 − 100 + 150 + 90 − 135 − 45 + 180 = 360
2. **位置の合計**: 始点 (0, 0)・向き θ = 0 から、各セグメントの終点を次の式で順に計算し、最後に (0, 0) に戻ること (誤差 1 px 未満)
   - 直線 (長さ L): `x += L × sin θ`、`y −= L × cos θ`
   - 円弧 (角度 α、半径 R、右が正): `κ = sign(α) / R`、`θ1 = θ + α` として `x += (cos θ − cos θ1) / κ`、`y −= (sin θ1 − sin θ) / κ`、`θ = θ1`
   - コース 1 の値で計算すると、終点は (0.02, −0.02) になる (長さを 0.1 px 単位で丸めた分の誤差)
3. **形を変えるとき**: どこか 1 か所の長さ・角度・半径を変えたら、向きが平行でない 2 本の直線 (コース 1 では東向きの `st3` と南向きの `st4`) の長さを連立方程式で解き直して閉じる。解いた長さが負や短すぎる (200 px 未満) ときは、変更の仕方を見直す
4. **実装での確認**: `Track` を作ったときの `closureError` (sim-lap.mjs の「閉じる誤差」) が 1 px 未満であること。`Track` は残った誤差を全周に配分して閉じるが、数十 px の誤差を配分すると形がゆがむので頼らない
5. **重なりの確認**: 中心線上で 700 px 以上離れた 2 点の距離が、上の表 (「近い場所」) の値を下回らないこと。sim-lap.mjs に確認を足す
