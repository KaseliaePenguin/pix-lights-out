# 車の挙動の仕様

状態: **初版 (2026-09-25)**。数値は初期値。テストプレイで調整する前提で、調整の方針を各節に書く。
ルール面 (DRS の使用条件、ゴースト、コース復帰など) は `docs/design/game-design.md` を参照。

単位: 時間 = 秒、距離 = px (ワールド座標。カメラ倍率 1.0 なので画面の px と同じ)、速度 = px/秒、加速度 = px/秒²、角度 = ラジアン (表では度も併記)。更新は固定タイムステップ `dt = 1/60 秒`。

## 0. 挙動の方針

- **アーケード寄り、グリップ重視**。車は基本的に向いている方向に進み、横滑り (ドリフト) で曲がることはない
- 差がつくのは **ブレーキポイント** と **ライン取り**。速すぎると曲がりきれずに外にふくらむ (アンダーステア)
- 限界に近づくとスキール音、限界を超えるとタイヤ痕とスピードの損失で知らせる
- 計算は単純な式で、全パラメータを 1 つの設定オブジェクト (`CarParams`) にまとめる。M4 でサーバーと共有するため DOM に依存しない

## 1. 車の寸法 (想定値)

**アートとの整合が必要**。以下は想定値で、art-director がスプライトの大きさを決めたら当たり判定と車輪位置を合わせて更新する。

| 項目 | 想定値 | 備考 |
| --- | --- | --- |
| スプライト | 16 × 32 px (幅 × 長さ) | 画面 800×600 で 1 周約 14,000 px のコースに対し、最高速で 1 秒に車 13 台分進む (実際の F1 とほぼ同じ比率) |
| 当たり判定 (向き付きの長方形) | 14 × 30 px | スプライトより 1 px ずつ内側 |
| 車輪の位置 (路面判定用) | 中心から前後 ±10 px、左右 ±5 px の 4 点 | |
| コース幅との関係 | 標準コース幅 48 px = 車 3 台分 | コース幅も寸法に合わせて変える |

寸法を変える場合は、コース幅・グリッド間隔 (40 px)・スリップストリームの距離 (120 px)・接触関連の距離も同じ比率で見直す。

## 2. 座標系と状態

- x は右向き、y は下向き (Canvas と同じ)。画面の上 = 北
- 向き θ: 0 = 北 (上)、時計回りが正。前方ベクトル `f = (sin θ, −cos θ)`、右方ベクトル `r = (cos θ, sin θ)`
- Canvas の `rotate(θ)` にそのまま渡せる (スプライトは上向きで描く)

車の状態:

| 変数 | 意味 |
| --- | --- |
| `x, y` | 車の中心の位置 |
| `θ` | 向き |
| `sF` | 前方向の速度 (負なら後退) |
| `sR` | 横方向の速度 (接触などで生じる残り。通常は 0) |
| `steer` | 実際のステア量 -1〜1 (入力を滑らかにしたもの) |
| `fSlip` | スリップストリームの効き 0〜1 |
| `fDrs` | DRS の効き 0〜1 |
| `wear` | タイヤの摩耗 0〜1 |
| `compound` | タイヤの種類 (soft / hard) |
| `spinTimer` | スピンの残り時間 |

速度ベクトルは `v = f × sF + r × sR`。

入力 `Controls`: `throttle` 0〜1、`brake` 0〜1、`steerInput` -1〜1、`drsPressed`、`resetPressed`。キーボードでは 0 か 1。

## 3. 1 フレームの更新順序

1. `Controls` を読む (スピン中・自動運転中・復帰中は無視)
2. ステアの平滑化 (4 節)
3. 車輪 4 点の路面を調べ、グリップ倍率・追加減速を求める (7 節)
4. タイヤ・DRS などを含めたグリップ倍率 `G` と最高速 `Veff` を求める (5・10・11・12 節)
5. 旋回: 向き θ を更新 (6 節)
6. 前後方向: `sF` を更新 (5 節)
7. 横方向の残り速度 `sR` を減衰 (6.4 節)
8. 位置を更新: `(x, y) += v × dt`
9. 壁との衝突 (9.2 節)
10. 全車の移動後に、車同士の衝突 (9.1 節)
11. スリップストリーム・DRS の状態、摩耗を更新 (11・12・10 節)
12. 演出の判定 (スキール音、タイヤ痕、火花) (8 節)

## 4. ステア入力の平滑化

キーボードの 0/1 入力をそのまま使うとカクつくため、`steer` を目標値 `steerInput` に一定の速さで近づける。

| 状況 | 変化の速さ |
| --- | --- |
| 目標に向かって大きくなる (0 → ±1) | 6.0 /秒 (0 → 1 まで 0.17 秒) |
| 0 に戻る (キーを離した) | 10.0 /秒 (1 → 0 まで 0.10 秒) |
| 逆方向に切り返す | まず 10.0 /秒 で 0 まで戻し、その後 6.0 /秒 で逆へ |

ゲームパッドのアナログ入力は平滑化しない。デッドゾーン 0.15 を除いたあと `sign(x) × |x|^1.5` で応答を柔らかくする。

## 5. 前後方向 (加速・最高速・ブレーキ・惰性・後退)

### 5.1 パラメータ

| 名前 | 値 | 意味 |
| --- | --- | --- |
| `vBase` | 420 px/秒 | 基本の最高速 (表示 315 km/h) |
| `accel0` | 360 px/秒² | 停止時の加速度 |
| `brakeDecel` | 450 px/秒² | 最大ブレーキの減速度 (グリップ倍率 1.0 のとき) |
| `coastBase` | 30 px/秒² | アクセルを離したときの減速 (定数部分) |
| `coastDrag` | 70 px/秒² | アクセルを離したときの減速 (最高速での空気抵抗分) |
| `reverseAccel` | 150 px/秒² | 後退の加速度 |
| `reverseMax` | 90 px/秒 | 後退の最高速 |
| `reverseDelay` | 0.3 秒 | 停止中にブレーキを押し続けてから後退に入るまで |

### 5.2 最高速

```
Veff = vBase × (1 + 0.08 × fSlip + 0.10 × fDrs)
```

- スリップストリームと DRS は足し算で重なる (両方で +18%、495.6 px/秒)
- ピットレーン・自動運転中は `min(Veff, 180)` (game-design.md 8.3 節)
- タイヤの種類・摩耗は最高速に影響しない

### 5.3 加速度の計算

アクセルとブレーキを同時に押した場合は **ブレーキを優先** し、アクセルは 0 として扱う。

```
s = sF (前進中、s ≥ 0)
aEngine = throttle × accel0 × surfaceAccel × (1 − (s / Veff)²)
aBrake  = brake × brakeDecel × Gbrake
aCoast  = (1 − throttle) × (coastBase + coastDrag × (s / vBase)²)
aScrub  = アンダーステアによる減速 (6.3 節)
aSurface = コース外の追加減速 (7 節)

sF += (aEngine − aBrake − aCoast − aScrub − aSurface) × dt
```

- `(1 − (s/Veff)²)` は速度が上がるほど加速が鈍る形で、空気抵抗も含んでいる。`s > Veff` のとき (スリップストリームが切れた直後など) は負になり、自然に減速する
- ブレーキ・惰性・追加減速で `sF` が 0 をまたいだら 0 で止める (後退には後退の操作でのみ入る)
- `Gbrake` = タイヤのグリップ (10 節) × 路面のブレーキ倍率 (7 節)

### 5.4 後退

- `sF ≤ 5` の状態でブレーキだけを `reverseDelay` (0.3 秒) 押し続けると後退モード
- 後退モード: ブレーキ入力で `reverseAccel` で後ろに加速 (最大 `reverseMax`)、アクセル入力は後退を止めるブレーキとして働く (`brakeDecel`)。停止したら前進に戻る
- 後退中の旋回は向きが逆になる (6 節の `sign(sF)`)

### 5.5 目安の数値 (グリップ 1.0)

| 項目 | 値 |
| --- | --- |
| 0 → 400 px/秒 | 2.15 秒 (580 px) |
| 0 → 410 px/秒 | 2.6 秒 |
| 最高速 420 → 160 のブレーキ | 約 150 px、0.5 秒 |
| 最高速 420 → 230 のブレーキ | 約 120 px、0.37 秒 |
| 最高速 420 → 300 のブレーキ | 約 85 px、0.24 秒 |
| 最高速でアクセルを離したとき | 約 100 px/秒² で減速 |

ブレーキポイントを 0.1 秒 (最高速で 42 px) 間違えると、ヘアピンではブレーキ距離の約 3 割になる。この感度が「ブレーキ勝負」の面白さの元なので、ブレーキ距離が短すぎると感じたら `brakeDecel` を下げる (400 にすると 420 → 160 が約 170 px)。

## 6. 旋回とグリップ限界

### 6.1 パラメータ

| 名前 | 値 | 意味 |
| --- | --- | --- |
| `latGrip` | 450 px/秒² | 横方向に出せる最大の加速度 (グリップ倍率 1.0 のとき) |
| `yawMaxLow` | 3.0 rad/秒 (172°/秒) | 低速での最大旋回速度 |
| `yawRampSpeed` | 40 px/秒 | これより遅いと旋回速度が速度に比例して小さくなる (止まっていると回れない) |
| `steerDemand` | 1.15 | フルステアで要求する横加速度 = `latGrip × 1.15` (わずかに限界を超える) |
| `scrubRate` | 0.5 | 限界を超えた分の何割を減速にするか |
| `scrubMax` | 120 px/秒² | アンダーステアによる減速の上限 |
| `brakeGripLoss` | 0.25 | フルブレーキ中は横グリップが 25% 減る |

### 6.2 旋回の計算

```
s = |sF|
// フルステアで出せる旋回速度 (速度が上がるほど小さくなる)
yawLimit = min(yawMaxLow × min(1, s / yawRampSpeed), latGrip × steerDemand / s)   // s = 0 のときは 0
yawCmd   = steer × yawLimit × sign(sF)

// 横グリップの限界
aLatMax  = latGrip × G
aReq     = s × |yawCmd|                 // この旋回に必要な横加速度
uReq     = aReq / aLatMax               // グリップ使用率 (1 を超えると限界超え)

yaw = uReq > 1 ? yawCmd / uReq : yawCmd // 限界を超えた分は曲がらない = アンダーステア
θ += yaw × dt
```

`G` (横グリップの倍率) = タイヤ (10 節) × 路面 (7 節) × `(1 − brakeGripLoss × brake)` × DRS が開いていれば 0.9。

考え方:

- 限界内なら入力どおりに曲がる。限界を超えると、そのときの速度で曲がれる最小半径 `R = s² / aLatMax` までしか曲がらず、コーナーが狭ければ外にふくらむ
- `yawLimit` を速度に応じて小さくしてあるので、**172 px/秒以上ではフルステアの要求は常に `latGrip × 1.15`** になる。つまりキーを押しっぱなしにすると新品のタイヤでもわずかに限界を超え (スキール音が鳴り、少し減速する)、当て舵で押し引きすると静かに速く曲がれる。摩耗したタイヤほど超過が大きくなり、アンダーステアが強くなる
- ブレーキを踏みながら曲がると横グリップが減るので、「まっすぐブレーキ → 離して曲がる」が速い

### 6.3 アンダーステアの減速

```
aScrub = uReq > 1 ? min(scrubMax, scrubRate × (aReq − aLatMax)) : 0
```

例: 新品のソフト (G = 1.08) でフルステア → 超過は 517.5 − 486 = 31.5 → 16 px/秒²。摩耗したハード (G = 0.77) なら超過 171 → 86 px/秒²。

### 6.4 横方向の残り速度

接触や壁で生じた横方向の速度 `sR` は、毎フレーム 0 に向かって減らす。

```
sR を 0 に向かって min(|sR|, 600 × 路面のグリップ倍率 × dt) だけ減らす
```

通常走行では `sR = 0` のまま (向きを変えると速度の向きも一緒に変わる)。

### 6.5 見た目の滑り角

グリップ限界付近では、車の絵だけを少し内側に向けて「タイヤが滑っている」感じを出す (当たり判定・進行方向は変えない)。

```
描画用の向き = θ + sign(yaw) × clamp((uReq − 0.9) × 25°, 0°, 6°)
```

### 6.6 コーナーの限界速度の目安

`v = √(latGrip × G × R)` (R はレーシングラインの半径)

| R (px) | ハード新品 (0.96) | 基準 (1.00) | ソフト新品 (1.08) |
| --- | --- | --- | --- |
| 55 (ヘアピン) | 154 | 157 | 163 |
| 65 (シケイン) | 168 | 171 | 178 |
| 90 | 197 | 201 | 209 |
| 110 | 218 | 222 | 231 |
| 150 | 255 | 260 | 270 |
| 200 | 294 | 300 | 312 |
| 240 | 322 | 329 | 342 |
| 300 | 360 | 367 | 382 |
| 400 | 416 | 424 (全開) | 441 (全開) |

低速側の旋回限界: 40〜172 px/秒 では `yawMaxLow` 3.0 rad/秒 で決まり、フルステアでの最小半径は 120 px/秒で 40 px。

## 7. 路面

車輪 4 点それぞれの路面を調べ、グリップとブレーキは 4 点の平均、追加減速は 4 点の合計 (各 1/4) で決める。片輪だけ芝生に落ちたときに少しだけ遅くなるようにするため。

| 路面 | グリップ倍率 | ブレーキ倍率 | 加速倍率 `surfaceAccel` | 速度の目安上限 | 上限を超えているときの追加減速 |
| --- | --- | --- | --- | --- | --- |
| アスファルト | 1.00 | 1.00 | 1.00 | なし | 0 |
| 縁石 | 0.92 | 0.90 | 1.00 | なし | 0 |
| ピットレーン | 1.00 | 1.00 | 1.00 | なし (速度制限は別) | 0 |
| 芝生 | 0.60 | 0.50 | 0.70 | 180 px/秒 | 350 px/秒² |
| 砂利 | 0.45 | 0.40 | 0.50 | 110 px/秒 | 550 px/秒² |

```
aSurface = Σ(車輪 i) 0.25 × (sF > 上限_i ? 追加減速_i : 0)
surfaceAccel = 4 輪の平均 (加速度にかける)
```

- 4 輪とも芝生で 400 px/秒 のまま突っ込むと、約 0.7 秒・200 px で 180 px/秒 まで落ちる。砂利なら約 0.5 秒で 110 px/秒 まで落ちる
- 上限以下では追加減速はなく、グリップと加速が落ちるだけ (芝生からは自力でコースに戻れる)
- 壁 (タイヤバリア) は路面ではなく衝突物として扱う (9.2 節)
- 調整: コース外が「得」になっている場所 (ショートカット) を見つけたら、その場所を砂利にするかチェックポイントのゲートで無効にする。数値を強くしすぎると 1 回のミスで勝負が決まるので、芝生の上限は 150〜200 の範囲で調整する

## 8. 限界の演出 (スキール音・タイヤ痕)

| 演出 | 条件 | 強さ |
| --- | --- | --- |
| スキール音 | `uReq ≥ 0.9` かつ速度 ≥ 120 px/秒、アスファルトか縁石の上 | 音量 = `clamp((uReq − 0.9) / 0.3, 0, 1)`。再生速度 = `0.9 + 0.3 × s / vBase` |
| タイヤ痕 | `uReq ≥ 1.0` かつ速度 ≥ 150 px/秒 (アスファルト・縁石) | 後輪 2 点から線を描く (不透明度 35%、`uReq` が 1.3 以上なら 50%) |
| タイヤ痕 (ブレーキ) | フルブレーキ (`brake = 1`) を始めてから 0.25 秒間、速度 ≥ 300 px/秒 | 前輪 2 点から薄い線 (不透明度 20%) |
| スピン中 | スピン中は常に | スキール音最大、4 輪からタイヤ痕 |

スキール音は「限界の手前 (0.9)」から鳴り始めるのが重要。キーボードでフルステアを保つと 1.15 前後になって鳴り続けるので、プレイヤーは「鳴らないように当て舵する」ことを覚える。

## 9. 接触 (衝撃)

### 9.1 車同士

判定: 当たり判定の長方形 (14 × 30 px、向き付き) 同士を分離軸判定 (SAT) で調べ、めり込み量 `depth` と法線 `n` (A から B へ向かう単位ベクトル) を求める。ゴーストの組み合わせ (game-design.md 7.10 節) は判定しない。

処理:

```
J  = max(0, (vA − vB) · n)          // 接近速度 = 衝撃の強さ (px/秒)
cA = vA · n                          // A が B に向かう速さ
cB = −vB · n                         // B が A に向かう速さ

// 1. 押し戻し
1 人用: A と B をそれぞれ depth / 2 ずつ法線方向に離す
マルチ: 自車だけを depth 分押し戻す (相手の位置は予測値のため動かさない)

// 2. 反発 (質量は全車同じ、反発係数 e = 0.2)
vA −= (1 + e) / 2 × J × n
vB += (1 + e) / 2 × J × n

// 3. 当てた側の判定
cA − cB > 20 なら A が「当てた側」、cB − cA > 20 なら B、差が 20 以内なら両方とも「当てた側」

// 4. 当てた側への追加の減速 (体当たりを損にする)
当てた側の速度ベクトル ×= (1 − min(0.30, J / 800))

// 5. 当てられた側は押されて速くならない
当てられた側の前方向速度 sF が接触前より大きくなったら、接触前の値に戻す

// 6. スピン
J ≥ 300 のとき、当てた側はスピン
J ≥ 300 かつ 当てられた側の横から当たった (|n · 当てられた側の r| > 0.7) なら、当てられた側もスピン
```

- 同じ 2 台の組み合わせでは、最後の衝撃から 0.2 秒以内の衝撃は適用しない (押し戻しだけ行う) (network.md と同じ)
- 速度ベクトルを変えたあとは、`sF`・`sR` を新しい速度ベクトルから計算し直す (横方向の成分は 6.4 節で減衰する)
- マルチ: 自車に適用した `J` と `n` を `collision` メッセージで送り、相手が未検出なら相手側で同じ計算をして自分の車に適用する。当てた側の判定は両者の速度から同じ式で決まるので、両クライアントで一致する

強さの目安:

| J (px/秒) | 状況の例 | 結果 |
| --- | --- | --- |
| 〜40 | 並走中に軽くこする | 押し戻しのみ。火花なし |
| 40〜150 | ブレーキングで軽く追突 | 火花、当てた側が 5〜19% 減速 |
| 150〜300 | 大きく追突、横からぶつける | 火花、画面揺れ、当てた側が 19〜30% 減速 |
| 300〜 | ブレーキを忘れて突っ込む | 当てた側がスピン (横からなら両方) |

### 9.2 壁 (タイヤバリア)

```
J = max(0, −v · n)                   // n は壁から車に向かう法線
押し戻し: めり込み分を n 方向へ
法線方向の速度: vN ← −0.2 × vN (はね返り)
接線方向の速度: vT ← vT × (1 − min(0.5, J / 600))
J ≥ 350 かつ 壁への進入角が 45° 以上 → スピン
```

演出 (火花・画面揺れ) の条件は車同士と同じ。

### 9.3 スピン

| 項目 | 値 |
| --- | --- |
| 時間 | 1.0 秒 (この間は操作を受け付けない) |
| 回転 | 開始時 8 rad/秒、1.0 秒かけて 0 まで直線的に減らす。回転方向は衝撃の向きから決める (衝撃が車の右側なら反時計回り) |
| 減速 | 500 px/秒² (速度ベクトルの大きさを減らす。向きは変えない = 滑りながら回る) |
| 終了後 | その時点の向き・速度のまま操作が戻る。逆向きなら逆走警告、止まっていればコース復帰が使える |

スピン中は向き θ と進行方向が一致しないので、スピン中だけ速度ベクトルを向きと切り離して扱い、終了時に `sF = v · f`、`sR = v · r` で戻す。

## 10. タイヤ (種類と摩耗)

### 10.1 グリップ

```
タイヤのグリップ = compoundGrip × wearFactor(wear)

compoundGrip: ソフト 1.08、ハード 0.96

wearFactor(w) = 1 − 0.08 × w               (w < 0.7)
              = 0.944 − 0.5 × (w − 0.7)     (w ≥ 0.7、いわゆる「崖」)
w は 1.0 で止める (wearFactor の最小値 0.794)
```

タイヤのグリップは横グリップ `G` とブレーキ `Gbrake` の両方にかかる。最高速・加速には影響しない。

| 状態 | ソフト | ハード |
| --- | --- | --- |
| 新品 (w = 0) | 1.080 | 0.960 |
| w = 0.35 | 1.050 | 0.933 |
| w = 0.70 (崖の手前) | 1.020 | 0.906 |
| w = 0.85 | 0.939 | 0.834 |
| w = 1.00 | 0.858 | 0.762 |

### 10.2 摩耗

```
L = max(min(uReq, 1.5), 0.8 × brake)                // タイヤへの負荷 (限界超えも数える)
wear += k × (s / vBase) × (0.4 + 0.6 × L) × dt

k: ソフト 0.0155 /秒、ハード 0.0064 /秒
```

- 速度に比例して減るので、止まっていれば減らない
- 限界を超えてこする (`uReq > 1`) ほど早く減る → 丁寧に走る人が長持ちする
- 目標: 普通に走って 1 周でソフト 0.34 前後、ハード 0.14 前後。実装後にデバッグ表示で 1 周の摩耗を測り、ソフト 0.30〜0.38 / ハード 0.12〜0.16 に入るよう `k` を調整する
- ソフトは 2 周で 0.68 (崖の手前)、3 周目で崖に入る。ハードは 3 周で 0.42 程度
- タイムアタックでは摩耗しない (`wear` を 0 に固定)
- 予選・決勝では摩耗する

### 10.3 ラップタイムへの影響 (シミュレーションの目安)

game-design.md 11.2 節のコース案で、理想走行のラップタイム:

| タイヤ | ラップ |
| --- | --- |
| ソフト新品 | 39.6 秒 |
| 基準 (1.0) | 40.2 秒 |
| ハード新品 | 40.5 秒 |
| ソフト w = 1.0 | 41.5 秒 |

ソフトとハードの差は新品で約 0.9 秒/周。崖に入ったソフトはハードより約 1 秒遅い。

## 11. スリップストリーム

条件 (前にいる車 L と自車 M について、毎フレーム全車を調べる):

```
L の後端 = L の位置 − L の f × 15
d = |M の位置 − L の後端|
角度1 = (M の位置 − L の位置) の向き と (−L の f) のなす角
角度2 = M の θ と L の θ の差

有効: d ≤ 120 かつ 角度1 ≤ 20° かつ 角度2 ≤ 30° かつ M の sF ≥ 200 かつ L がゴーストの関係でない
```

- 効き `fSlip`: 有効な間は +2.0 /秒 (0 → 1 に 0.5 秒)、無効になったら −2.0 /秒 で下げる
- 効果: 最高速 +8% (5.2 節の式)。加速の式が `Veff` を使うので、高速域の加速も良くなる
- 複数の車が条件を満たしても効果は 1 台分
- HUD の表示は `fSlip` を 3 段 (0.33 / 0.66 / 1.0 以上で 1〜3 本)
- 予選・タイムアタックでは効かない (全車ゴーストで重なって走ることがあり不自然なため。タイムアタックのゴーストカーからも受けない)

目安: 2,200 px のバックストレートで、スリップストリームだけで約 0.2 秒、DRS だけで約 0.37 秒、両方で約 0.6 秒縮まる (理想走行のシミュレーション)。前車の 0.5 秒後ろにいれば、ストレートの終わりで横に並べる計算。

## 12. DRS

- 使用条件は game-design.md 7.6 節。自車の状態として `drsAvailable` (この周の区間で使える)、`drsOpen` を持つ
- 開く: `drsAvailable` かつ DRS 区間内で `drsPressed`
- 閉じる: ブレーキ入力 (`brake > 0`)、区間の終了ライン通過、スピン、ピットの自動運転
- 効き `fDrs`: 開くと +5.0 /秒 (0.2 秒で 1)、閉じると −5.0 /秒
- 効果: 最高速 +10% (5.2 節)。開いている間は横グリップ ×0.9 (6.2 節) → 開いたままコーナーに入るとふくらむが、ブレーキで自動的に閉じるので通常は問題にならない

## 13. ピットレーンの自動運転

- ピット入口ラインを越えると `Controls` を無視し、ピットレーンの経路 (折れ線) を CPU と同じ pure pursuit で追う
- 速度制限 180 px/秒。入口で 180 を超えていれば `brakeDecel` で自動的に減速
- ボックス手前で停止位置に合わせて減速し、停止 2.0 秒 → 出口まで 180 px/秒
- 自動運転中も位置・向き・速度は通常の物理で更新する (ワープしない)。路面判定・壁判定は行わない

## 15. 調整の方針

優先順位 (上ほど先に合わせる):

1. **曲がる感触**: ヘアピン (R 55) と高速コーナー (R 300) を走り、「ブレーキを踏めば曲がれる」「速すぎるとふくらむ」がはっきり分かるか。分かりにくければ `steerDemand` を上げる (1.2〜1.3) と限界超えが強調される
2. **ブレーキ勝負**: 最高速からヘアピンまでのブレーキ距離 (約 150 px) が短すぎ・長すぎでないか。`brakeDecel` で調整
3. **ラップタイム**: 43〜48 秒に入るか。外れたらコースの直線の長さで調整 (車の性能は 1・2 で決めたものを動かさない)
4. **コース外**: 芝生に落ちたときの損失がミス 1 回につき 0.5〜1.5 秒程度か
5. **追い抜き**: CPU 相手に DRS 区間で 0.5 秒差から並べるか。並べなければ `slipBonus` / `drsBonus` を上げる
6. **タイヤ**: 8.1 節 (game-design.md) の 4 つの戦略の差が 1 秒以内に収まるか

実装時は F3 のデバッグ表示で `s`、`uReq`、`G`、路面、`fSlip`、`fDrs`、`wear` を常に見られるようにする。
