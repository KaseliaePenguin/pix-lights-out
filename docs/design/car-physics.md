# 車の挙動の仕様

状態: **第 4 版・改訂 2 (2026-09-25)**。全面改訂。数値は初期値で、ゲーム内の調整パネルで詰める前提 (18・19 節)。

改訂 2 (実装後の反映): 実装 (コミット 7d4506f) を試走したユーザーが「ハンドルやブレーキが急すぎて扱いにくい」と評価し、調整パネルで `brakeDecel` 312.5、`steerRise` 3.5、`yawMaxLow` 2.0 を選んだ (ユーザーの決定)。これを初期値にした。関連して実装で変えた値 (`steerReturn` 6、`driftEnterTime` 0.08 秒 (新設)、`driftKickAngle` 5°、`driftAngleResponse` 6、`driftReleaseTime` 0.3) も初期値にした。最初の案の値は `src/shared/carParams.ts` の `specCarParamValues` に残っている。表の「最初の案」の列もその値。

第 4 版の理由 (ユーザーの評価と決定): 第 3 版の挙動を試走した評価は「気持ちよく曲がるのではなく、我慢して曲がる」だった。ユーザーは、**グリップ走行とドリフトを使い分ける操作感** にやり直すと決めた。普段はグリップで鋭く曲がる (ハンドルを切ればすぐ向きが変わり、ほとんど減速しない)。ブレーキをかけながらハンドルを切るとドリフトに入る。やり直すのは車の挙動とコース (game-design.md 11 章) で、タイムアタック・ゴースト・HUD・画面・素材・オンライン (network.md) はそのまま使う。F1 らしさ (DRS、スリップストリーム、タイヤ、ピット) も残す。

ルール面 (DRS の使用条件、ゴースト、コース復帰など) は `docs/design/game-design.md` を参照。

単位: 時間 = 秒、距離 = px、速度 = px/秒、加速度 = px/秒²、角度 = ラジアン (表では度も併記)。更新は固定タイムステップ `dt = 1/60 秒`。

## 0. 挙動の方針

### 0.1 第 3 版の「我慢」の原因 (第 3 版の仕様を読み直した結果)

| 原因 | 第 3 版の仕様 | 第 4 版での対処 |
| --- | --- | --- |
| 限界を超えると罰しかない | `steerDemand` 1.15 のため、キーボードでフルステアすると常に限界を約 15% 超える。そこで曲がり方を `yawCmd / uReq` に削り (アンダーステア)、さらに最大 150 px/秒² 減速していた | フルステアがちょうど限界になるようにする (`steerDemand` 1.0)。限界を超えても曲がりを削りすぎず、減速も弱める (6 節)。滑らせたい人にはドリフトを用意する (7 節) |
| ステアの立ち上がりが遅い | キーボードで 0 → 1 に 0.17 秒、切り返しに約 0.27 秒 | 最初の案では 0 → 1 を約 0.07 秒にした。しかし試走で「急すぎる」とされ、改訂 2 で約 0.29 秒に戻した (4 節)。「我慢」の原因は立ち上がりの遅さより、限界超えの罰のほうが大きかったと判断する |
| 曲がれる速度が低く、アクセルを踏めない時間が長い | 横グリップ 562.5、ブレーキ 562.5、加速 450 | 横グリップ 750、加速 500 (5・6 節)。ブレーキは改訂 2 で 312.5 (穏やかに長く効く)。コース幅も 60 → 80 px に広げる (game-design.md 11 章) |
| 滑らせても得がない | 限界超えはスキール音・減速・タイヤ摩耗の損だけ | ドリフトの長さに応じて **ERS ブースト** が溜まり、出口で加速できる (8 節) |
| 狭い道幅と近い壁に対して速度が高く、リスクばかり大きい | コース幅 60 px、直線の芝生 40 px、壁の減速も大きい | コース幅 80 px、芝生 60 px 以上。壁は減速を軽くし、沿って滑るようにする (10・11 節) |

### 0.2 気持ちよさの柱 (調整に迷ったらここに戻る)

1. **キーボードで扱いやすい、穏やかな操作** (改訂 2 で追加。ユーザーの決定): キーを押した瞬間に車の向きが変わり始めるが、ハンドルは約 0.3 秒かけて切れ、ブレーキも穏やかに効く。0/1 のキー入力でも車がぎくしゃくせず、切りすぎ・止まりすぎにならない。「即応」より「扱いやすさ」を優先する。グリップ走行中は、ハンドルを切っただけでは減速しない
2. **フルステアが最速の曲がり方**: キーボードで押しっぱなしにすると、グリップの限界ちょうどで曲がる。当て舵はいらない。差がつくのはブレーキの位置とライン、そしてグリップかドリフトかの選び方
3. **限界を超えても罰より「滑る楽しさ」**: 限界を超えたときの損は小さくする。わざと滑らせたいときはドリフトに入れ、その角度をハンドルとアクセルで操る
4. **ドリフトの出口で得をする**: ドリフトを続けた時間に応じて ERS (エネルギー回生) が溜まり、ドリフトを抜けた瞬間にブーストとして出る。F1 の ERS を借りた演出で、長く上手に滑るほど得をする
5. **使い分けに奥行きがある**: 低速のヘアピンではドリフトが速く、高速コーナーではグリップが速い。中速コーナーはどちらでも走れるが、ドリフトはタイヤを多く減らす。コーナーごとに「どちらで行くか」を考える余地を作る (17 節)
6. **やりすぎの罰は残すが、軽く**: ドリフト中にブレーキを長く踏み続けると回る。ただしスピンは短く (0.6 秒)、すぐ走り直せる

### 0.3 実装の前提 (第 3 版から引き継ぐ)

- 計算は単純な式にし、全パラメータを 1 つの設定オブジェクト `CarParams` にまとめる (18 節)。M4 でホストの Web Worker と共有するため、DOM に依存させない (`src/shared/`)
- 車は `Controls` だけを見て動く (game-design.md 5.3 節)
- 調整パネルで値を実行中に変えられるように、`CarParams` から毎フレーム値を読む。値から前もって計算した値をキャッシュしない (19 節)

## 2. 座標系・状態・描画

### 2.1 座標系

- 物理・判定・コースデータの座標は **画面 px (800×600 基準)** で持つ。1 ドット = 2 px
- x は右向き、y は下向き (Canvas と同じ)。ワールドの上 = 北
- **向き θ: 0 = 北 (上) 向き、時計回りが正**。前方ベクトル `f = (sin θ, −cos θ)`、右方ベクトル `r = (cos θ, sin θ)`
- 車のスプライトは北向きに描かれているので、描画時の角度の補正は要らない
- `Math.atan2(dy, dx)` で求めた角度 `a` を θ に変換するときは `θ = a + π/2`

### 2.2 描画

描画の方式 (ワールド層の拡大、カメラの回転) は style-guide.md §1 と game-design.md 10.5 節に従う。物理は丸めない (丸めるのは描画だけ)。

### 2.3 車の状態

| 変数 | 意味 |
| --- | --- |
| `x, y` | 車の中心の位置 (px) |
| `θ` | 車体の向き |
| `sF`, `sR` | 車体から見た前方向・右方向の速度。速度ベクトル `v = f × sF + r × sR` |
| `mode` | `grip` / `drift` / `spin` (7・9 節) |
| `driftDir` | ドリフトの向き。+1 = 右に曲がるドリフト、−1 = 左 |
| `beta` | ドリフト角の大きさ (0 以上)。車体の向きと進行方向の差 |
| `driftTime` | ドリフトに入ってからの時間 |
| `ersCharge` | このドリフトで溜めた ERS (秒)。段階 `ersTier` 0〜3 はここから決まる (8 節) |
| `boostTier`, `boostTimer` | 出ているブーストの段階と残り時間 |
| `steer` | 実際のステア量 −1〜1 (入力を平滑化したもの) |
| `fSlip`, `fDrs` | スリップストリーム・DRS の効き 0〜1 |
| `wear`, `compound` | タイヤの摩耗 0〜1 と種類 |
| `spinTimer` | スピンの残り時間 |

入力 `Controls`: `throttle` 0〜1、`brake` 0〜1、`steerInput` −1〜1、`steerIsAnalog`、`drsPressed`、`resetPressed`。キーボード (←→ ハンドル、Z アクセル、X ブレーキ。game-design.md 5.1 節) では、throttle・brake は 0 か 1、steerInput は −1 / 0 / 1。

## 3. 1 フレームの更新順序

1. `Controls` を読む (スピン中・自動運転中・復帰中は無視)。アクセルとブレーキを同時に押したらブレーキを優先し、アクセルは 0 とする
2. ステアの平滑化 (4 節)
3. 車輪 4 点の路面を調べ、グリップ・ブレーキ・加速の倍率と追加減速を求める (10 節)
4. タイヤ・DRS などを含めたグリップ倍率 `G` と最高速 `Veff` を求める (5・12〜14 節、ブーストは 8 節)
5. モードの遷移を判定する (grip → drift の開始、drift の終了、スピンの開始。7・9 節)
6. モードごとの更新: `grip` は 6 節、`drift` は 7 節、`spin` は 9 節。向き θ と速度を更新する
7. ERS の溜まりとブーストの更新 (8 節)
8. 位置を更新する: `(x, y) += v × dt`
9. 壁との衝突 (11.2 節)
10. 全車の移動後に、車同士の衝突 (11.1 節)
11. スリップストリーム・DRS の状態、摩耗を更新する (12〜14 節)
12. 演出の判定 (スモーク、タイヤ痕、スキール音、ブーストの見せ方。16 節)

## 4. ステア入力

### 4.1 キーボード・十字キー (`steerIsAnalog = false`)

0/1 の入力で一瞬で切り替わると唐突なので、`steer` を目標値 `steerInput` へ一定の速さで近づける。改訂 2 では、キーボードで扱いやすい **穏やかな速さ** にする (ユーザーの調整)。

| 状況 | 変化の速さ (初期値) | 所要時間 | 最初の案 | 調整の幅 |
| --- | --- | --- | --- | --- |
| 目標に向かって大きくなる (0 → ±1) | `steerRise` 3.5 /秒 | 0 → 1 に約 0.29 秒 | 15 (0.07 秒) | 2〜25 |
| 0 に戻る (キーを離した) | `steerReturn` 6 /秒 | 1 → 0 に約 0.17 秒 | 20 (0.05 秒) | 3〜30 |
| 逆方向に切り返す | 0 までは `steerReturn`、そこから `steerRise` | ±1 → ∓1 に約 0.45 秒 | 約 0.12 秒 | |

キーを軽く叩くと浅く切れるので、キーボードでも切る量を調整できる。

### 4.2 ゲームパッドのアナログスティック (`steerIsAnalog = true`、M3)

第 3 版と同じ。

```
x = axes[0]
|x| < 0.15 なら 0
それ以外: n = (|x| − 0.15) / 0.85
          steerInput = sign(x) × n^1.5
steer = steerInput          // 平滑化しない
```

- トリガーはデッドゾーン 0.05 を除いて 0〜1 に広げ直し、`throttle` / `brake` に使う
- キーボードと同時に使った場合は、ステアは絶対値が大きい方を採用する。採用した方がキーボード・十字キーなら 4.1 節の平滑化を通す
- CPU の AI もアナログ扱いで、ステア量を直接出す

## 5. 前後方向 (加速・最高速・ブレーキ・惰性・後退)

### 5.1 パラメータ

| 名前 | 初期値 | 第 3 版 | 調整の幅 | 意味 |
| --- | --- | --- | --- | --- |
| `vBase` | 525 | 525 | 480〜575 | 基本の最高速 (表示 315 km/h) |
| `accel0` | 500 | 450 | 450〜600 | 停止時の加速度 |
| `brakeDecel` | **312.5** (最初の案 650) | 562.5 | 250〜800 | 最大ブレーキの減速度 (グリップ 1.0 のとき)。改訂 2 でユーザーが選んだ値 |
| `coastBase` / `coastDrag` | 37.5 / 87.5 | 同じ | | アクセルを離したときの減速 (定数部分 / 最高速での空気抵抗分) |
| `reverseAccel` / `reverseMax` / `reverseDelay` | 187.5 / 112.5 / 0.3 秒 | 同じ | | 後退 |

### 5.2 最高速

```
Veff = vBase × (1 + min(bonusCap, 0.08 × fSlip + 0.10 × fDrs + boostTop))
```

- `boostTop` はブースト中の段階ごとの上乗せ (8 節、ブーストなしなら 0)
- 上乗せの合計には上限 `bonusCap` 0.25 を設ける (スリップストリーム + DRS + ブーストを全部重ねても +25%、656 px/秒)
- ピットレーン・自動運転中は `min(Veff, 225)`
- タイヤの種類・摩耗は最高速に影響しない

### 5.3 加速度 (grip モード)

```
s = max(sF, 0)
aEngine  = throttle × accel0 × surfaceAccel × (1 − (s / Veff)²)
aBoost   = ブースト中なら boostAccel[段階] (8 節)、それ以外は 0
aBrake   = brake × brakeDecel × Gbrake
aCoast   = (1 − throttle) × (coastBase + coastDrag × (s / vBase)²)
aScrub   = 限界超えの減速 (6.3 節)
aSurface = コース外の追加減速 (10 節)

sF += (aEngine + aBoost − aBrake − aCoast − aScrub − aSurface) × dt
```

- `s > Veff` のとき (ブースト・スリップストリームが切れた直後) は `aEngine` が負になり、自然に減速する
- 減速の項で `sF` が 0 をまたいだら 0 で止める
- `Gbrake` = タイヤのグリップ × 路面のブレーキ倍率

### 5.4 後退

第 3 版と同じ。`sF ≤ 6` の状態でブレーキだけを 0.3 秒押し続けると後退モードに入る。後退中はドリフトに入らない。

### 5.5 目安の数値 (グリップ 1.0、初期値で計算)

| 項目 | 値 (改訂 2) | 最初の案 (650) | 第 3 版 |
| --- | --- | --- | --- |
| 0 → 500 px/秒 | 約 1.95 秒・約 655 px | 同じ | 2.2 秒・730 px |
| 最高速 525 → 400 のブレーキ | 約 0.30 秒・約 138 px | 0.17 秒・77 px | |
| 最高速 525 → 300 のブレーキ | 約 0.56 秒・約 228 px | 0.30 秒・124 px | |
| 最高速 525 → 200 のブレーキ | 約 0.83 秒・約 295 px | 0.44 秒・160 px | 0.50 秒・180 px |

改訂 2 のブレーキは第 3 版より長く、穏やかに効く。ブレーキ距離が長いぶん、ブレーキを始める位置の差 (0.1 秒 = 最高速で 52 px) がブレーキ距離に占める割合は小さく、ブレーキの位置の失敗が許されやすい。

## 6. グリップ走行 (grip モード)

### 6.1 パラメータ

| 名前 | 初期値 | 第 3 版 | 調整の幅 | 意味 |
| --- | --- | --- | --- | --- |
| `latGrip` | 750 | 562.5 | 650〜900 | 横方向に出せる最大の加速度 (グリップ倍率 1.0) |
| `yawMaxLow` | **2.0 rad/秒 (115°/秒)** (最初の案 3.6) | 3.0 | 1.5〜4.5 | 低速での最大旋回速度。改訂 2 でユーザーが選んだ値 |
| `yawRampSpeed` | 40 | 50 | 25〜60 | これより遅いと旋回速度が速度に比例して小さくなる |
| `steerDemand` | **1.00** | 1.15 | 0.95〜1.10 | フルステアで要求する横加速度 = `latGrip × steerDemand` |
| `understeerSoftness` | 0.5 | (1.0 相当) | 0〜1 | 限界を超えたときに曲がりを削る強さ (6.2 節)。1 で第 3 版と同じ、0 で削らない |
| `scrubRate` / `scrubMax` | 0.25 / 80 | 0.5 / 150 | 0〜0.5 / 0〜150 | 限界超えの減速 |
| `brakeGripLoss` | 0.2 | 0.25 | 0〜0.3 | ブレーキ中の横グリップの低下 (フルブレーキで 20%) |
| `lateralDecay` | 1,200 | 750 | 800〜2,000 | 横方向の速度 `sR` を 0 に戻す速さ (ドリフトの出口で、進行方向を車体に合わせる速さ) |

### 6.2 旋回の計算

```
s = |sF|
yawLimit = min(yawMaxLow × min(1, s / yawRampSpeed), latGrip × steerDemand / s)   // s = 0 なら 0
yawCmd   = steer × yawLimit × sign(sF)

aLatMax  = latGrip × G
aReq     = s × |yawCmd|
uReq     = aReq / aLatMax                    // グリップ使用率

yaw = uReq > 1 ? yawCmd / uReq^understeerSoftness : yawCmd
θ += yaw × dt
```

`G` (横グリップの倍率) = タイヤ (12 節) × 路面 (10 節) × `(1 − brakeGripLoss × brake)` × DRS が開いていれば 0.9。

考え方:

- `steerDemand` が 1.0 なので、グリップ 1.0 の路面でフルステアすると、`uReq` がちょうど 1 になる (`latGrip / yawMaxLow` 以上の速度の場合。改訂 2 の値では 375 px/秒 以上、最初の案では約 208 px/秒 以上。それより遅いと旋回速度の上限で決まり、限界の手前で曲がる)。改訂 2 の値では、375 px/秒 未満のコーナーを grip で曲がると旋回速度の上限に縛られ、グリップを使い切れない。そのため低速コーナーではドリフトが大きく有利になる (7.5 節、21 節)。**キーボードで押しっぱなしにするのが最も速い曲がり方** になり、当て舵はいらない。ソフトタイヤ (1.08) なら `uReq` は約 0.93 で、限界の少し手前になる
- 限界を超えるのは、グリップが落ちたとき (芝生・縁石、ブレーキを踏みながら浅く切ったとき、摩耗したタイヤ) だけ。そのときも `understeerSoftness` 0.5 のため、第 3 版より曲がりを削る量が少ない。例: `uReq` 1.2 なら第 3 版は 83% まで曲がりを削ったが、第 4 版は 91% まで曲がる
- 曲がる速さは入力にすぐ付いてくる (ステアの立ち上がり約 0.29 秒 + 旋回にかかる時間なし)。車体の重さによる遅れは入れない

### 6.3 限界超えの減速

```
aScrub = uReq > 1 ? min(scrubMax, scrubRate × (aReq − aLatMax)) : 0
```

限界内 (`uReq ≤ 1`) では減速しない (「ハンドルを切っても減速が少ない」)。第 3 版では、新品のソフトでもフルステアで約 20 px/秒² 減速し続けていたが、第 4 版では 0 になる。

### 6.4 横方向の残り速度

接触・壁・ドリフトの出口で生じた横方向の速度 `sR` は、毎フレーム 0 に向かって減らす。

```
sR を 0 に向かって min(|sR|, lateralDecay × 路面のグリップ倍率 × dt) だけ減らす
```

ドリフトの出口 (ドリフト角 6° 未満) では `sR` は速さの約 10% 以下なので、約 0.05 秒で車体の向きに進むようになる。

### 6.5 見た目の滑り角 (grip モード)

限界付近では、車の絵だけを少し内側に向けて「タイヤが粘っている」感じを出す。当たり判定と進行方向は変えない。

```
描画用の向き = θ + sign(yaw) × clamp((uReq − 0.9) × 25°, 0°, 6°)
```

drift モードでは車体の向き θ そのものが進行方向からずれるので、この補正は使わない。

### 6.6 コーナーの限界速度の目安 (grip)

`v = √(latGrip × G × R)` (R はレーシングラインの半径)。コース 1 の各コーナーの値は game-design.md 11.2 節。

| R (px) | ハード新品 (0.96) | 基準 (1.00) | ソフト新品 (1.08) |
| --- | --- | --- | --- |
| 100 | 268 | 274 | 285 |
| 150 | 329 | 335 | 349 |
| 200 | 379 | 387 | 402 |
| 250 | 424 | 433 | 450 |
| 300 | 465 | 474 | 493 |
| 368 以上 | 全開 (525) | 全開 | 全開 |

低速側の旋回の限界: 40〜375 px/秒 では `yawMaxLow` の 2.0 rad/秒 で決まる (最初の案では 40〜208 px/秒、3.6 rad/秒)。フルステアでの最小半径は、速度 ÷ 2.0 (150 px/秒 で 75 px、300 px/秒 で 150 px)。上の表のうち、半径 R が速度 ÷ 2.0 より小さいコーナーは、grip ではこの表の速度で曲がれない。

## 7. ドリフト (drift モード)

### 7.1 入り方

grip モードで、次の条件が **同時に** そろった瞬間に drift モードに入る。

| 条件 | 初期値 | 調整の幅 |
| --- | --- | --- |
| ブレーキ `brake ≥ driftEnterBrake` | 0.3 (キーボードでは X を押している) | |
| ステア `|steer| ≥ driftEnterSteer` | 0.5 (キーボードでは ←→ を押して約 0.14 秒後) | 0.3〜0.8 |
| 上の条件がそろい続けた時間 ≥ `driftEnterTime` (改訂 2 で新設) | 0.08 秒 | 0〜0.2 |
| 前進速度 `sF ≥ driftEnterSpeed` | 200 px/秒 | 150〜280 |
| 車輪が 2 輪以上コース上 (アスファルト・縁石・ピットレーン) | | |
| 後退中・スピン中・自動運転中・復帰中でない | | |

- ブレーキとハンドルはどちらを先に押してもよい。ブレーキを踏みながら切り始めても、切りながらブレーキを踏んでも入る
- ブレーキは入るきっかけで、入ったあとは離してよい (離すのが普通)
- `driftEnterTime` は、ブレーキとハンドルが一瞬重なっただけで意図せずドリフトに入らないようにするため (実装で追加)
- 入った瞬間に `driftDir = sign(steer)`、`beta = driftKickAngle` (5°。最初の案 8°)、`driftTime = 0`、`ersCharge = 0` とする。車体がすっと内側を向く「入った」手応えを出すため
- 200 px/秒 未満でブレーキ + ハンドルを使った場合は、第 3 版と同じグリップの旋回 (ブレーキでグリップが少し落ちる) になる。低速の切り返しや、コース復帰後の発進で意図せず滑らないようにする
- DRS は開いていればブレーキで閉じる (14 節)。ドリフト中は DRS を開けない

### 7.2 ドリフト角の操作 (維持・カウンター)

ドリフト中は、車体の向き θ と進行方向 φ (速度ベクトルの向き) を分けて扱う。`θ = φ + driftDir × beta`。

**目標角** `betaTarget` をハンドルとペダルで決め、`beta` をそこへ近づける。

```
u = steer × driftDir          // +1 = ドリフトの向きに切る (内側)、−1 = カウンター (逆に切る)

u ≥ 0 のとき: betaTarget = driftAngleNeutral + (driftAngleIn − driftAngleNeutral) × u
u < 0 のとき: betaTarget = driftAngleNeutral × (1 + u)            // 全力のカウンターで 0°

ハンドルを離した状態 (|steer| < 0.1) が driftReleaseTime 続いたら: betaTarget = 0
betaTarget += throttle × driftAngleThrottle
driftTime ≥ driftBrakeGrace なら: betaTarget += brake × driftAngleBrake

beta += (betaTarget − beta) × min(1, driftAngleResponse × dt)
```

| 名前 | 初期値 | 調整の幅 | 意味 |
| --- | --- | --- | --- |
| `driftKickAngle` | 5° (最初の案 8°) | 0〜15° | 入った瞬間の角度 |
| `driftAngleNeutral` | 20° | 12〜30° | ハンドルがまっすぐのときの目標角 |
| `driftAngleIn` | 45° | 35〜55° | ドリフトの向きにフルに切ったときの目標角 |
| `driftAngleThrottle` | +5° | 0〜10° | アクセルを踏むと角度が増える (パワーオーバー) |
| `driftAngleBrake` | +12° | 0〜20° | ブレーキを踏むと角度が増える (入った直後は除く) |
| `driftBrakeGrace` | 0.4 秒 | 0.2〜0.6 | 入った直後、ブレーキで角度が増えない時間 (入るときに踏んでいるブレーキで回らないように) |
| `driftReleaseTime` | 0.3 秒 (最初の案 0.4) | 0.2〜0.8 | ハンドルを離したまま、これだけ経つとドリフトを抜けに行く |
| `driftAngleResponse` | 6 /秒 (最初の案 8) | 4〜14 | 目標角への追従の速さ (時定数約 0.17 秒) |

キーボードでの操作の感覚:

| 操作 | 目標角 | 結果 |
| --- | --- | --- |
| 内側のキーを押し続け + アクセル | 50° | 深い角度で小さく回る。そのぶん減速も大きい |
| 内側のキーを押し続け + アクセルを離す | 45° | 角度を保ったまま少し減速する |
| 内側のキーを短く押したり離したりする | 20〜50° の間 | 角度 (曲がり具合) を細かく調整できる。これが「ドリフトの奥行き」 |
| キーを離す | 20° → 0.3 秒後に 0° | ゆるくなり、そのまま抜ける |
| 外側のキー (カウンター) | 0° | 素早く抜ける |
| ドリフト中にブレーキを踏み続ける (アクセルは 0 扱い) | 最大 57° | 小さく回るが減速が大きい。長く踏み続けるとスピン (9 節) |

### 7.3 ドリフト中の進み方

```
s = |v|
Gd = タイヤ × 路面のグリップ倍率 (ブレーキ・DRS による低下は含めない)
gain(s) = s ≤ driftGainSpeedLow ならば driftLatLow
          s ≥ driftGainSpeedHigh ならば driftLatHigh
          その間は直線でつなぐ
aLat = latGrip × Gd × gain(s) × min(beta / driftAngleRef, driftLatMaxFactor)

φ += driftDir × aLat / max(s, 60) × dt                  // 進行方向が曲がる

aEngine = throttle × accel0 × surfaceAccel × driftThrottleMul × (1 − (s / Veff)²)
aDrag   = driftDrag × sin(beta)                         // 横を向いて進むことによる減速
aBrake  = brake × brakeDecel × Gbrake × driftBrakeMul
aCoast  = (1 − throttle) × (coastBase + coastDrag × (s / vBase)²)
s += (aEngine − aDrag − aBrake − aCoast − aSurface) × dt     // 0 未満にしない

θ = φ + driftDir × beta
v = s × (sin φ, −cos φ)、sF = v · f、sR = v · r             // 接触・壁の処理は sF・sR で共通に扱う
```

| 名前 | 初期値 | 調整の幅 | 意味 |
| --- | --- | --- | --- |
| `driftLatLow` | 1.25 | 1.0〜1.5 | 低速でのドリフトの横グリップ倍率 (grip の 1.25 倍曲がれる) |
| `driftLatHigh` | 0.75 | 0.5〜1.0 | 高速でのドリフトの横グリップ倍率 (grip の 0.75 倍しか曲がれない) |
| `driftGainSpeedLow` / `High` | 250 / 450 px/秒 | | 倍率を切り替える速度の範囲 |
| `driftAngleRef` | 40° | 30〜50° | この角度で `gain(s)` どおりの横グリップになる |
| `driftLatMaxFactor` | 1.25 | 1.0〜1.5 | 深い角度での上乗せの上限 |
| `driftDrag` | 260 px/秒² | 150〜400 | 横を向いて進むことによる減速 (45° で 184、20° で 89) |
| `driftThrottleMul` | 0.85 | 0.6〜1.0 | ドリフト中のエンジンの効き |
| `driftBrakeMul` | 0.5 | 0.3〜0.8 | ドリフト中のブレーキの効き |

考え方:

- **ドリフト角が曲がり具合を決める**。角度を深くするほど小さく回れるが、`aDrag` で速度を失う。角度を浅くすると速度を保てるが、大回りになる。ハンドル (角度) とアクセル (速度) で、曲がり具合と速さを両立させる
- **ドリフトは低速で強く、高速で弱い** (`gain(s)`)。250 px/秒 以下では grip より 25% 強く曲がれるので、ヘアピンではドリフトが速い。450 px/秒 以上では grip の 75% しか曲がれないので、高速コーナーでドリフトすると外に膨らむ。この 1 つの設定で、コーナーごとの使い分けが生まれる (17 節)
- アクセルを踏み続けると速度が上がって回転半径が大きくなり、外へ流れる。「アクセルで外に、角度で内に」という操作が覚えやすい
- 目安: 基準グリップ・フルアクセルのとき、45° では約 400 px/秒、20° では約 470 px/秒 で、エンジンの力と `aDrag` が釣り合う

### 7.4 抜け方

次のどれかで grip モードに戻る。

| 抜け方 | 条件 | ERS ブースト (8 節) |
| --- | --- | --- |
| きれいに抜ける | `beta < driftExitAngle` (6°) の状態が `driftExitTime` (0.1 秒) 続いた | 出る |
| 速度が落ちた | `s < driftMinSpeed` (120 px/秒) | 出る |
| コース外 | 3 輪以上がコース外 (芝生・砂利) | 出ない (溜めた分は失う) |
| 壁・車との衝突 | 衝撃の強さ J ≥ 187.5 px/秒 | 出ない |
| スピン | 9 節 | 出ない |
| 自動運転・コース復帰に入った | | 出ない |

抜けたときは `sF = v · f`、`sR = v · r` とし、残った横方向の速度は 6.4 節で素早く消える。

| --- | --- | --- | --- |
| 改訂 2 (ユーザーの値) | 40.35 秒 | 37.50 秒 | **−2.86 秒/周** (T7 −1.18、T9 −0.48、T11 −0.63 秒) |

- 最初の案の値では逆に、ドリフトに入るブレーキと `aDrag` の損がブーストの得を上回っていた
- 設計の目標は「ヘアピンでドリフトが 0.1〜0.4 秒速い、1 周で 1 秒前後」。今の差 (2.86 秒) をどうするかは 21 節の未決定事項 (ユーザーに確認中)

## 8. ERS ブースト (ドリフトのご褒美)

ドリフトで溜めたエネルギーを、抜けた瞬間にブーストとして出す。名前は F1 のエネルギー回生システム (ERS) から借りた (実在の商標ではない一般名詞)。

### 8.1 溜まり方

- ドリフト中、`beta ≥ ersMinAngle` (15°) かつ コース外の車輪が 2 輪以下のとき、`ersCharge += dt`
- 段階 `ersTier`: `ersCharge` が 0.5 秒で 1、1.1 秒で 2、1.8 秒で 3
- 段階が上がった瞬間に、演出 (16 節) と HUD の ERS ゲージ (game-design.md 10.1 節) で知らせる
- ドリフトが 7.4 節の「出ない」抜け方で終わったら、溜めた分は 0 に戻す

### 8.2 ブースト

きれいに抜けたとき (または速度が落ちて抜けたとき)、`ersTier ≥ 1` ならブーストを出す。

| 段階 | 溜める時間 | 追加の加速 `boostAccel` | 最高速の上乗せ `boostTop` | 続く時間 |
| --- | --- | --- | --- | --- |
| 1 | 0.5 秒 | 150 px/秒² | +4% | 0.5 秒 |
| 2 | 1.1 秒 | 200 px/秒² | +6% | 0.8 秒 |
| 3 | 1.8 秒 | 250 px/秒² | +8% | 1.1 秒 |

- ブーストは grip モードで `aBoost` として足す (5.3 節)。`s ≥ Veff` のときは足さない (最高速を超えて加速し続けないように)
- ブースト中にブレーキを踏むと、その場で終わる
- ブースト中に次のドリフトに入ったら、ブーストはその場で終わる (ブーストを重ねない)
- 見積もり (最初の案): ヘアピン (出口 約 300 px/秒) で段階 2 を出すと、出口の速度が約 100 px/秒 上がり、次の直線の終わりまでに約 0.15〜0.25 秒得をする。実測のヘアピンごとの差は 7.5 節
- タイムアタック・予選・決勝のすべてで有効。スリップストリーム・DRS と重なるが、最高速の上乗せの合計は 5.2 節の上限 (+25%) まで

### 8.3 ERS とタイヤの関係 (戦略)

ドリフトはタイヤを多く減らす (12.2 節)。決勝で「ドリフトを多用して速く走り、タイヤを早く使い切る」か「grip で丁寧に走ってタイヤを持たせる」かの選択になる。F1 らしいタイヤ戦略 (game-design.md 8 章) とつながる。

## 9. スピン

### 9.1 スピンになる条件

| 原因 | 条件 | スピンの時間 |
| --- | --- | --- |
| ドリフトのやりすぎ | ドリフト中に `beta ≥ driftSpinAngle` (52°) の状態が `driftSpinTime` (0.35 秒) 続いた | 短い (`spinTimeLight` 0.6 秒) |
| 壁 | 衝撃 J ≥ 500 px/秒 かつ 壁への進入角が 60° 以上 (11.2 節) | 短い (0.6 秒) |
| 車同士の接触 | 11.1 節 (J ≥ 375) | 長い (`spinTimeContact` 1.0 秒。体当たりを損にするため第 3 版のまま) |

- `beta` の目標角は、アクセル (+5°) でもブレーキ (+12°) でも、片方だけでは 52° を超えない (45 + 5 = 50°)。**内側にフルに切ったままブレーキを踏み続けたとき** (45 + 12 = 57°) だけスピンする。入った直後 0.4 秒はブレーキで角度が増えないので、ドリフトに入るためにブレーキを踏んでいてもすぐには回らない。目安として、内側に切ったままブレーキを約 1 秒踏み続けると回る
- **実装での結果 (改訂 2)**: 上のブレーキによるスピンは、実際には起きない。ブレーキで先に速度が落ち、角度が 52° に 0.35 秒とどまる前に `driftMinSpeed` などでドリフトが抜けるため。罰を残すか、今のまま罰なしにするかはユーザーに確認中 (21 節)。壁と接触によるスピンは仕様どおり
- 回る前の兆候: `beta` が 48° を超えたら、スキール音を最大にし、車体の絵を小刻みに揺らす (16 節)。気づいてブレーキを離せば回らない

### 9.2 スピンの動き

| 項目 | 短いスピン (ドリフト・壁) | 長いスピン (接触) |
| --- | --- | --- |
| 時間 (操作を受け付けない) | 0.6 秒 | 1.0 秒 |
| 回転 | 開始時 6 rad/秒 から 0 まで直線的に減らす (約 100°)。向きはドリフトの向き (壁なら衝撃の向き) | 開始時 8 rad/秒 から 0 まで (約 230°) |
| 減速 | 450 px/秒² | 625 px/秒² |
| 終了後 | その時点の向き・速度のまま grip モードに戻る | 同じ |

- 短いスピンの約 100° は「くるっと向きが変わって止まりかける」程度で、すぐ走り直せる。損は約 1.5〜2 秒
- スピン中は速度ベクトルを向きと切り離して扱い、終了時に `sF = v · f`、`sR = v · r` で戻す
- 逆向きで止まったら逆走警告、止まっていればコース復帰が使える (game-design.md 7.11 節)

## 10. 路面

車輪 4 点それぞれの路面を調べ、グリップ・ブレーキ・加速は 4 点の平均、追加減速は 4 点の合計 (各 1/4) で決める。

| 路面 | グリップ | ブレーキ | 加速 | 速度の上限 | 上限を超えているときの追加減速 | 第 3 版からの変更 |
| --- | --- | --- | --- | --- | --- | --- |
| アスファルト (白線を含む) | 1.00 | 1.00 | 1.00 | なし | 0 | |
| 縁石 | 0.97 | 0.95 | 1.00 | なし | 0 | 0.92 → 0.97。乗っても損がほとんどない。ドリフトの ERS も溜まる |
| ピットレーン | 1.00 | 1.00 | 1.00 | なし | 0 | |
| 芝生 | 0.70 | 0.55 | 0.75 | 260 px/秒 | 400 px/秒² | 0.60 / 225 / 437.5 から緩めた |
| 砂利 | 0.50 | 0.45 | 0.60 | 180 px/秒 | 500 px/秒² | 0.45 / 137.5 / 687.5 から緩めた |

目安 (4 輪とも、500 px/秒 で突っ込んだとき):

| 路面 | アクセルを離した場合 | アクセルを踏んだまま |
| --- | --- | --- |
| 芝生 (→ 260 px/秒) | 約 0.5 秒 | 約 1.2 秒 |
| 砂利 (→ 180 px/秒) | 約 0.6 秒 | 約 0.9 秒 |

- 方針: **芝生は「減速するが即死ではない」**。少しはみ出してもアクセルを戻さずにコースに戻れる。砂利は、ブレーキの大失敗 (ヘアピン・1 コーナーの突っ込みすぎ) を受け止める場所で、芝生より強く減速する
- ドリフト中の車輪がコース外に出てもドリフトは続く (グリップが下がるので膨らむ)。3 輪以上コース外でドリフトは終わる (7.4 節)。ERS はコース外 2 輪までなら溜まる
- コース外を通ると得をする場所 (ショートカット) は、コースデータで砂利にするか、チェックポイントのゲートで無効にする。ヘアピンの内側は、縁石の先を砂利にする (game-design.md 11.1 節)
- 壁 (タイヤバリア) は路面ではなく衝突物として扱う (11.2 節)

## 11. 接触

### 11.1 車同士

第 3 版と同じ (反発係数 0.2、当てた側の追加減速 最大 30%、当てられた側は速くならない、J ≥ 375 で当てた側がスピン (長いスピン)、同じ 2 台は 0.2 秒以内の再適用なし、マルチでは `collision` で相手に伝える)。

```
J  = max(0, (vA − vB) · n)
押し戻し: 1 人用は両方を depth / 2 ずつ、マルチは自車だけ depth
反発:     vA −= (1 + e) / 2 × J × n、vB += (1 + e) / 2 × J × n   (e = 0.2)
当てた側: cA − cB > 25 なら A、cB − cA > 25 なら B、差が 25 以内なら両方
当てた側の速度ベクトル ×= (1 − min(0.30, J / 1000))
当てられた側の sF が接触前より大きくなったら接触前の値に戻す
J ≥ 375: 当てた側はスピン。当てられた側が横から (|n · r| > 0.7) 当てられたなら、当てられた側もスピン
```

第 4 版での追加:

- ドリフト中の車が J ≥ 187.5 の接触を受けたら、ドリフトを終える (ERS は失う)。J < 187.5 ならドリフトを続ける
- ブースト中に J ≥ 187.5 の接触をしたら、ブーストを終える (ブーストで体当たりしても得にならないように)
- 強さの目安と演出の条件は第 3 版のまま (50 未満は押し戻しのみ、50 以上で火花、187.5 以上で画面揺れ)

### 11.2 壁 (タイヤバリア)

**方針: 罰を軽くし、壁に沿って滑るようにする**。触れただけで止まったり、弾かれて逆を向いたりしない。

```
J  = max(0, −v · n)                        // n は壁から車に向かう法線
押し戻し: めり込み分を n 方向へ
法線方向の速度: vN ← −wallRestitution × vN               (0.3。少し弾かれる)
接線方向の速度: vT ← vT × (1 − min(wallTangentLossMax, J / wallTangentLossDiv))   (最大 0.35、J / 1000)
向きの補正: 壁への進入角が wallAlignMaxAngle (35°) 未満なら、車体の向きを壁の接線方向へ
            最大 wallAlignRate (6 rad/秒) で寄せる (かすったら壁に沿って走り続けられる)
J ≥ spinImpulseWall (500) かつ 進入角 ≥ spinWallMinAngle (60°) → 短いスピン
```

| 名前 | 初期値 | 第 3 版 | 調整の幅 |
| --- | --- | --- | --- |
| `wallRestitution` | 0.3 | 0.2 | 0.1〜0.5 |
| `wallTangentLossDiv` / `wallTangentLossMax` | 1,000 / 0.35 | 750 / 0.5 | |
| `wallAlignMaxAngle` / `wallAlignRate` | 35° / 6 rad/秒 | なし | 0〜45° / 0〜10 |
| `spinImpulseWall` / `spinWallMinAngle` | 500 / 60° | 437.5 / 45° | |

- 目安: 450 px/秒 で 20° の角度でかすると、J ≈ 154。速度は約 15% 落ちるが、向きが壁に沿って直るので、そのまま走れる。90° で正面からぶつかるとスピンする
- ドリフト中に J ≥ 187.5 で壁に当たったら、ドリフトを終える (ERS は失う)
- 演出 (火花・画面揺れ・音) の条件は第 3 版のまま

## 12. タイヤ (種類と摩耗)

### 12.1 グリップ

第 3 版と同じ。

```
タイヤのグリップ = compoundGrip × wearFactor(wear)
compoundGrip: ソフト 1.08、ハード 0.96
wearFactor(w) = 1 − 0.08 × w               (w < 0.7)
              = 0.944 − 0.5 × (w − 0.7)     (w ≥ 0.7、崖)
```

タイヤのグリップは、grip の横グリップ `G`、ブレーキ `Gbrake`、ドリフトの横グリップ `Gd` のすべてにかかる。摩耗したタイヤではドリフトも膨らむ。最高速・加速には影響しない。

### 12.2 摩耗

```
grip モード:  L = max(min(uReq, 1.5), 0.8 × brake)
drift モード: L = driftWearLoad × (0.5 + beta / driftAngleIn)       // 45° で driftWearLoad × 1.5
wear += k × (s / vBase) × (0.4 + 0.6 × L) × dt

k: ソフト 0.0155 /秒、ハード 0.0064 /秒 (第 3 版と同じ)
driftWearLoad: 1.3
```

- ドリフト中は、同じ速度の grip 走行の約 2 倍の速さで摩耗する (45° で `L` = 1.95、grip の限界ちょうどは `L` = 1.0)
- 目標: grip 中心に走って 1 周でソフト約 0.30、ドリフトを 3 か所使って約 0.36。実装後にデバッグ表示で測り、ソフト 0.30〜0.38 / ハード 0.12〜0.16 に入るよう `k` を調整する
- タイムアタックでは摩耗しない (`wear` = 0 に固定)

## 13. スリップストリーム

第 3 版と同じ (決勝のみ、前車の後端から 150 px 以内・角度 20° 以内・向きの差 30° 以内・速度 250 px/秒 以上で有効、効き `fSlip` は ±2.0 /秒、最高速 +8%)。

- ドリフト中の前車からも受けられる (前車の向き θ ではなく、進行方向 φ で角度を判定する)
- 最高速の上乗せは、DRS・ブーストと合わせて 5.2 節の上限 (+25%) まで

## 14. DRS

第 3 版と同じ。開く: 使える状態で DRS 区間内で `drsPressed`。閉じる: ブレーキ入力、区間の終わり、スピン、ピットの自動運転。効き `fDrs` ±5.0 /秒、最高速 +10%、開いている間は grip の横グリップ ×0.9。

- ドリフトにはブレーキで入るので、DRS を開いたままドリフトすることはない
- ドリフト中は DRS を開けない。ブースト中は開ける (最高速の上乗せは 5.2 節の上限まで)。T7 のヘアピンをドリフトで抜けてブーストを出し、そのまま DRS を開くのが、コース 1 のバックストレートの見せ場になる

## 15. ピットレーンの自動運転

第 3 版と同じ (ピット入口ラインを越えたら `Controls` を無視し、経路を pure pursuit で追う、速度制限 225 px/秒)。

- ピット入口ラインを越えた時点で、ドリフトとブーストを終える (ERS は失う)
- 自動運転中は grip モードだけを使う

## 16. 演出の要件 (見た目・音)

色・形・描き方は art-director、音の作り方は sound-designer が決める。ここでは **いつ・どのくらい出すか** だけを決める。

| 演出 | 条件 | 強さ・内容 |
| --- | --- | --- |
| スキール音 (grip) | `uReq ≥ 0.95` かつ 速度 ≥ 150、車輪がアスファルトか縁石 | 音量 = `clamp((uReq − 0.95) / 0.25, 0, 1)`。再生速度 = `0.9 + 0.25 × s / vBase`。外れたら 0.15 秒でフェード。キーボードでフルステアしたとき、基準グリップではかすかに鳴り、ソフトでは鳴らない |

## 19. 調整の方針と確認方法

### 19.1 調整パネルとの関係

- 調整パネル (実装済み、開発時だけ。F4 で開く。操作は game-design.md 12 章 M1) は、`CarParams` の値を実行中に書き換える。車は毎フレーム `CarParams` を読むので、書き換えた次のフレームから効く
- 調整パネルで 1 つでも初期値から変えている間は、自己ベスト・ゴーストを **保存しない** (違う物理でのタイムが記録に混ざらないように)。タイム表示の横に `TUNED` と出す
- 気に入った値は、調整パネルから書き出して `carParams.ts` の初期値に反映し、`physicsVersion` を上げる

### 19.2 優先順位 (上ほど先に合わせる)

1. **グリップの扱いやすさ**: キーボードで高速コーナー (コース 1 の T4) とヘアピン (T7) を grip で走る。「押した瞬間に曲がり始める」「急すぎない」「押しっぱなしで曲がれる」「減速を感じない」か。改訂 2 ではユーザーが穏やかな値 (`steerRise` 3.5、`yawMaxLow` 2.0) を選んだので、これを基準にする
2. **ブレーキ**: 最高速から T1・T8 までのブレーキ (改訂 2 の値で 525 → 400 px/秒 に約 138 px・0.30 秒、DRS を使った T8 ではもう少し長い) が短すぎ・長すぎでないか。`brakeDecel` で調整する
3. **ドリフトに入る・保つ・抜ける**: 入れたいときに確実に入るか (`driftEnterSpeed`・`driftEnterSteer`)、キーのタップで角度を調整できるか (`driftAngleResponse`・`driftAngleNeutral`)、抜けたいときにすぐ抜けるか (`driftReleaseTime`)
4. **使い分け**: 今はドリフトが 1 周 2.86 秒速すぎる (7.5 節、21 節)。ヘアピンでドリフトが grip より 0.1〜0.4 秒速く (ブーストを含む)、高速コーナー (T4) では grip のほうが 0.1 秒以上速いか。ドリフトが強すぎれば `driftLatLow` か `boostAccel` を下げ、弱すぎれば上げる。高速でドリフトが有利になっていたら `driftLatHigh` を下げる
5. **やりすぎの罰**: スピンが「自分のせい」と分かり、理不尽に感じないか。回りやすすぎれば `driftSpinAngle` を上げる
6. **ラップタイム**: game-design.md 11 章の目安 (上手な走りで約 37〜38 秒、AI の実測 37.50 秒) に近いか。コースの形は変えず、車の性能は 1〜5 で決めた値を動かさない。大きく外れたら原因を調べる
7. **コース外・壁**: 芝生に出たときの損がミス 1 回につき 0.3〜1.0 秒、壁にかすったときの損が 0.3 秒程度か
8. **追い抜き・タイヤ** (M2・M3): DRS 区間で 0.5 秒差から並べるか、戦略の差が 1 秒以内か

### 19.3 確認方法

- F3 のデバッグ表示に、`mode`、`beta`、`betaTarget`、`ersCharge` / `ersTier`、`boostTimer`、`s`、`uReq`、`G`、路面、`fSlip`、`fDrs`、`wear` を出す
- `scripts/sim-lap.mjs` に次を足す: (1) grip だけで走る AI と、ドリフトコーナー (game-design.md 11.2 節) でドリフトする AI のラップ・区間タイムの比較、(2) キーボード相当の 0/1 入力の AI、(3) 5.5 節・10 節の目安の数値の測定、(4) ドリフトに入る・抜ける・スピンの条件の単体確認

- CPU の AI (game-design.md 9 章) は、コースデータでドリフトの印が付いたコーナーでドリフトを使う。AI もプレイヤーと同じ物理で走る
- ゴースト: 位置と向きを記録するので、ドリフト中の車体の向きもそのまま再生される。スモークなどの演出を再生するため、ゴーストの記録にフラグ (drift 中、ブースト段階) を足した (実装済み。記録の形式 2、1 周 約 13 KB)
